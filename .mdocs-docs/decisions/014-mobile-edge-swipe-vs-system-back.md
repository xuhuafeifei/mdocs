# 014 — 手机左缘右滑开目录：接受系统返回手势上限

- **状态**：accepted
- **上下文**：窄屏要「左缘右滑开侧栏」。实现在 Web（`useEdgeSwipeOpen`）；Android 壳用 `systemGestureExclusionRects` 申请左缘。真机 APK 与手机浏览器仍常无效果。
- **决策**：认定主因是 **系统/浏览器返回手势抢左缘**（事件到不了 JS），不是 WebView 单独坏了。Exclusion 与放宽起滑带宽只作尽力缓解；**可靠入口保留汉堡按钮**，不承诺左缘右滑 100% 可用。
- **后果**：
  - 排查先分「触摸是否进页面」与「进了是否开门」，避免只改 Web 阈值空转。
  - 浏览器与 APK 同类限制；装新壳不能单独保证手势。
