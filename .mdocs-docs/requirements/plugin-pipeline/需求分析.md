# plugin-pipeline — 需求分析

> 一句话：用 **YAML 协议 + 可视化流水线编排器** 安装/接入插件；Skill/MCP × 安装方式 × 归属三维分类；Engram 系统自带默认不启用；安装物实例唯一；visitor 隔离；soul + skill meta 注入 Agent。

## 背景

- 一期 [`plugin-marketplace`](../plugin-marketplace/)：安装逻辑写死在 TS，Memorix/Engram 分支；拓展性差。
- [`agent-mcp-client`](../agent-mcp-client/)：通用挂 MCP；Engram 代调 `mem_session_start` 但未按 visitor 隔离，且该工具仍暴露给模型。
- Memorix：**废弃**。记忆主推 Engram。

## 目标

1. YAML 流水线解释器 + 系统/用户（tenant）两类定义；系统可改可恢复初始。
2. 安装物 → `plugins/install/<id>/`；插件数据 → `plugins-data/<id>/`；灵魂 → `soul/`（非 dataDir 根）。
3. Engram 自带流水线、用户选择安装；spawn 注入 project；隐藏危险 tools。
4. 装完 hook 写灵魂旁路文件（同级独立文件，卸载即删）；**改 Agent run** 注入 soul + skill meta。
5. 本期不做 Agent 编流水线；Tenant 危险步骤本期放开，后续收口。

## 非目标

- Memorix；旧 Engram `mdocs` 桶迁移；Agent 自动生成流水线；URL/exec 白名单（后续）。

## 验收标准

- [ ] YAML 可安装/卸载 Engram；二次安装 skip 下载。
- [ ] 未启用不 spawn；启用后 A/B project 隔离；Agent 不见 `mem_session_start`。
- [ ] soul 目录空壳 + 旁路；run 注入 soul；skill meta 进 system（无未点选全文）。
- [ ] 系统流水线可恢复初始。

## 本次变更（AI 安装台 · 已同意 / 首版落地 2026-10-30）

- 降新手复杂度：新建顶栏 **AI | 手动**；默认 AI。

- 编排 Agent **有 session**（kind=`plugin-pipeline`）；再装一个只清右侧 Id。
- 右栏本地草稿，装完留页引导退出；市场现成插件仍一键装；手动保留编排器（安装方式=模板预填）。

## 本次变更（编排器 UI v2 · 已同意 2026-10-30）

- 用户明确要求重做前端：市场三段式、拖拽步骤编排、Probe 独立、按步执行器、内嵌 AI 草稿。
