# plugin-pipeline — 增量：目录与启用模型统一

> **状态**：已同意（2026-10-31）· **已实现**  

> 父契约：[设计契约.md](./设计契约.md)；Skill 旧契约：[../user-agent-skills/设计契约.md](../user-agent-skills/设计契约.md)（存储将被本增量取代）  
> 动机：现网 `plugins/install` + 全局 `plugins-data` + 全局 `mcp-servers.json` + Skill 进 SQLite，心智混乱；按「实例一份软件 / 租户各一份配置与数据」统一。

## 一句话

**相同的是软件，不同的是配置和数据。** 系统插件 = 预填好的自定义插件；Skill 全私人；路径前缀由系统/工具写死，Agent 只填 `plugin-name` 与相对片段。

## 主轴

| 维度 | 含义 | 例子 |
|------|------|------|
| **实例只装一份（全局）** | 机器上的可执行物 / 安装产物，租户之间不重复装 | Engram 二进制、自定义插件二进制 |
| **租户各一份（私人）** | 流水线副本、插件数据、MCP 注册、Skill、soul | Engram 数据目录、私人 Skill、是否启用 |

「全局」≠「所有人自动开通」；只表示安装实体共用。开不开、怎么配，在 tenant。

## 目录约定（目标）

```text
{dataDir}/
  plugins-home/<plugin-name>/          # ★ 全局：安装实体（系统/自定义都在这）
    bin/…                              # 下载解压产物等
  plugins-catalog/<plugin-name>/       # ★ 全局：系统流水线母版（只读 / 可恢复）
    pipeline.yaml
    pipeline.yaml.default              # 可选

  tenant/{visitorId}/
    plugins/<plugin-name>/             # ★ 私人：已启用流水线（可改）
      pipeline.yaml
    plugins-data/<plugin-name>/        # ★ 私人：插件跑出来的数据
    mcp/<plugin-name>.json             # ★ 私人：按插件拆开的 MCP 配置（避免抢一个大 JSON）
    skills/<skill-name>/               # ★ 私人：Skill 真身（无全局 Skill）
      SKILL.md
    soul/                              # 已有
```

### 三问对照

| 问题 | 全局 | 私人（tenant） |
|------|------|----------------|
| **插件装在哪？** | `plugins-home/<name>/` | 不装第二份实体（自定义也进 home） |
| **数据写哪？** | 原则上不写 | `tenant/.../plugins-data/<name>/` |
| **流水线定义写哪？** | 母版 `plugins-catalog/` | 启用后的副本 `tenant/.../plugins/<name>/` |

### 命名

- 主键用 **`<plugin-name>`**（租户内唯一；实例侧 home 也按同名一份）。  
- 废弃「随机数字实例 id」作为主叙事（迁移期可兼容旧目录）。  
- Skill：`tenant/.../skills/<skill-name>/SKILL.md`；**没有全局 Skill**。

## 系统插件 vs 自己创建

本质相同，差别只在「表单是否预填」：

| | 系统插件（如 Engram） | 自己创建 |
|--|----------------------|----------|
| 母版 | `plugins-catalog` 带齐步骤 | 无母版 / 空骨架 |
| 启用后 | copy → `tenant/.../plugins/<name>/` | 直接写在该路径 |
| 装实体 | 需要时写入 `plugins-home/<name>/` | 同左 |
| MCP / 数据 | 写 **该访客** 的 `mcp/`、`plugins-data/` | 同左 |

### 「启用」三步（统一）

1. 确保 tenant 有流水线副本（系统：从 catalog 分发；自定义：已有或新建空稿）。  
2. 若 `plugins-home/<name>/` 尚无实体 → 跑安装步骤写入 home。  
3. 写好 tenant 侧 MCP / 数据目录约定（Engram：连接时注入数据根）。

未启用的访客：home 里可以已有二进制（别人装过），但没有自己的流水线/MCP → Agent 不挂。

## Engram（数据与连接）

- **二进制**：`plugins-home/engram/`（实例一份）。  
- **数据**：租户目录 `tenant/{vid}/plugins-data/engram/`（目标态）。  
- Engram 通过 env 认根：`ENGRAM_DATA_DIR` + `ENGRAM_PROJECT`。现网已支持；目标态在 **Agent 连接 / init** 时注入该访客的 `ENGRAM_DATA_DIR`。  
- 隔离边界由**连接时**的 env（及可选 project）决定；不是每人再装一份二进制。  
- stdio 进程：与「MCP 在 tenant」配套——按租户会话带上该租户 env（工具层约束），避免整实例一个进程却换不了 DATA_DIR。

无旧路径回落：不读全局 `plugins-data`，不迁旧 install。

## Skill

- 真身只在 `tenant/.../skills/<name>/`。  
- `upsert_skill`：系统定前缀；YAML/Agent 只给 **name**（及从 `plugins-home` 安装物按约定拷/读 `SKILL.md`），不拼 `plugins-data`、不写全局库 blob。  
- 对话引用 / hydrate 按 name 展开，读源为文件。

## MCP

- 配置全部在 `tenant/{vid}/mcp/<plugin-name>.json`。  
- 租户 Agent 只读该目录，不合并全局 `mcp-servers.json`。  
- 不同插件各写各文件。

## Agent / 流水线工具约束

- **禁止**模型填写绝对路径或自造 `plugins-data` / `tenant` 长前缀。  
- 工具只接受：`plugin-name`、相对安装物片段、Skill name。  
- 前缀由宿主解析：`plugins-home` / `tenant/.../plugins-data` / `skills` / `mcp`。

## Skill + CLI（路径与执行）

- **clone / 源码**：流水线步骤 `git_clone` → `plugins-home/<plugin-name>/`（`dest` 相对，默认 `.`）。仅 `https://`。  
- **Skill 正文**：仍 `upsert_skill` → `tenant/.../skills/<name>/SKILL.md`（说明怎么用，不是脚本仓库）。  
- **跑脚本**：Agent 工具 `run_plugin_cli`（白名单 `python3|python|node|npm|npx|uv|uvx`）；`list_plugin_home` 自测文件；`query_skill` 查私人 Skill。  
- args / cwd **只许相对路径**；系统拼 `plugins-home` 或 `cwd_root=data` 时拼租户 `plugins-data`。禁止 `~` / 绝对路径 / `..`。  
- **安装**：`submit_pipeline` 交草稿后，`install_pipeline` 写入 tenant 并跑解释器（可等待结束）；SSE `pipeline_job` 同步右栏。  
- 第三方 skill 若写死 `~/.xxx`：**不合约**，编排时改写成相对 home。

## 非目标（本增量文档）

- **不做旧路径兼容 / 迁移脚本**（未发版，本地可清 dataDir）。  
- 不改「流水线步骤类型闭集」业务语义（download/extract/exec/upsert_* 等仍可保留，落点按上表改）。  
- 不做「同名装两份」实体。

## 相对旧草案的漂移

| 旧草案 | 现契约 |
|------|------|
| `plugins/install/<随机id>/` | `plugins-home/<name>/` |
| `plugins/system|user|tenant/…` 混装 YAML | catalog 母版 + `tenant/.../plugins/` 副本 |
| 全局 `plugins-data/<key>/` | `tenant/.../plugins-data/<name>/` |
| 全局 `mcp-servers.json` | `tenant/.../mcp/<name>.json` |
| Skill → SQLite body | `tenant/.../skills/<name>/SKILL.md` |
| 随机 pipeline id 叙事 | `<plugin-name>` 租户唯一 |
