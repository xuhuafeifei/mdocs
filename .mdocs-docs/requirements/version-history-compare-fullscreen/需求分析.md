# version-history-compare-fullscreen — 需求分析

> 一句话：版本历史支持任选两个历史版做 Diff 对比，并把查看区做成可全屏。

## 背景

现有「版本历史」是左列表 + 右单版预览（md 转 Markdown / html iframe / sheet 摘要），可恢复非 head 版本。用户希望：

1. **对比两个历史版本**（不只看单个）
2. **全屏**查看，方便长文 diff

## 范围

| 做 | 不做 |
|----|------|
| 面板内「预览 / 对比」模式切换 | 服务端新增 compare API |
| 选择两个 commit，右侧用 `@lobehub/editor/renderer` 的 **`LexicalDiff`** | live Editor DiffHunk Accept/Reject；非 md 的 CodeDiff（一期不做） |
| 对话框可全屏 / 退出全屏 | 三路 merge、从 diff 直接恢复 |
| md / html / sheet 均可对比（统一成文本再 diff） | sheet 结构化格级 diff |

## 验收

- [ ] 能选两个不同 md commit，看到块级 LexicalDiff（旧/新标签）
- [ ] 同 commit 不能组成一对（或提示换一个）
- [ ] 全屏后预览/对比区域占满视口；可退出全屏；关闭面板仍可用
- [ ] md：blob 规范化为 `SerializedEditorState` 再进 `LexicalDiff`；一侧为 Markdown 时先转 Lexical
- [ ] html/sheet：对比不可用或有明确提示
- [ ] 恢复 / 隐藏自动发布等原能力不回归
