# server-file-logging — 设计契约

> **状态**：已同意（2026-10-10，对齐既有实现 + 默认文件级 error）  
> 抄 agent-demo 文件日志思路；**无前台管理**。

## 方案摘要

mdocs **已有**与 agent-demo 同构的文件日志（`useLogger` → 按日文件 + 大小轮转 + 保留天数清理）。本期只定产品口径并改默认：

| 项 | 约定 |
|----|------|
| 目录 | `{MDOCS_DATA_DIR\|~/.mdocs}/logs/`（相对 agent-demo 的 fgbg 模板路径，改到 mdocs dataDir） |
| 文件名 | `mdocs-YYYY-MM-DD.log`（过大则 `-1` `-2`…） |
| 文件级别默认 | **`error`**（含 fatal）；`MDOCS_LOG_LEVEL` 可改 |
| 控制台默认 | `info`（`MDOCS_CONSOLE_LEVEL`） |
| UI | **不做** |
| SQLite log 表 | **不做** |

未捕获异常：进程 `uncaughtException` / `unhandledRejection` 走 `log.error` 落盘。

## 变更触达

| 文件 | 改动 |
|------|------|
| `src/server/config/index.ts` | 文件默认 level → error |
| `src/server/main.ts` | 注册未捕获异常落盘 |

## 运维

```bash
# 看今天 error
tail -f ~/.mdocs/logs/mdocs-$(date +%F).log
```
