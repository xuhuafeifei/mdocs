# 用户 Agent Skill — 需求分析

> 一句话：访客可配置私人 skill；两入口引用；传输只带标记；Agent 用时合成 tool 往返展开（去重、越新越先）；本轮结束后前端清空标签。

## 背景

- 现有包内 **手册 skill** 是产品说明书，不是用户可配内容。
- 用户需要私人提示词宏；仅 `user`+`<skill>` 易被模型当成粘贴。
- 历史每轮全文展开会重复灌同一 skill；前端 sticky 常驻也别扭。

## 目标

1. 设置页 CRUD 私人 skill（访客私有）。
2. 智能助手 / 帮写可引用；**本轮成功结束后清空选中**。
3. 传输 / 落盘只带 `skillIds` + 原文。
4. 展开：合成 `load_user_skill`；去重；越新越先；原文走 `prompt()`。
5. system 标明已加载语义；normal / coding 共用。

## 非目标（本期不做）

- skill 下发 / 域共享；迁 AgentHarness；真注册供模型主动调 `load_user_skill`；slash；话题检测。

## 验收标准

- [ ] CRUD；两入口引用；成功结束后标签清空。
- [ ] jsonl 有 ids、无全文、无假 tool。
- [ ] 模型侧可见合成往返；同 id 单次请求全文不重复。
- [ ] 缺失 id 不 500；手册 tools 不变。
