# Sheet 冲突整表二选一 — 设计契约

> **状态**：已同意（2026-10-14）— 对话确认「要么接受我，要么接受别人」并「优化一下」。

## 方案摘要

| 项 | 约定 |
|----|------|
| 政策 | `sheet.mergePipeline = 'whole-document'`（新枚举；md 仍 `lexical-md-bridge`，html 仍 `raw-text`） |
| UI | `MergeView` 在 `whole-document` 分支；不跑 `buildThreeWayMergePlan` |
| 选择 | **用我的** = 发布 `conflict.localSnapshotContent`；**用别人的** = 发布 GET 到的远端 `content` |
| 发布 | 仍走 `updateDocument` + `version.merge`（与现网 merge 通道一致） |
| 预览 | 解析 workbook，展示各 tab：名、行×列、merge 段数；解析失败则提示「无法预览」仍可二选一 |
| 不做 | 单元格级 accept；JSON hunk；冲突页内嵌可编辑表格 |
