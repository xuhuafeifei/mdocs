# Sheet 冲突整表二选一 — 需求分析

> 一句话：`.sheet` 发布冲突时只提供「用我的 / 用别人的」整表选择，不做单元格或 JSON 行级 merge。

## 背景

md/html 冲突走三方行级 inline merge。sheet 若套同一 `raw-text` 管道，等于对工作簿 JSON 做行 diff——对用户抽象，且无法处理 merge 单元格几何不一致（3×5 vs 7×8）。

## 目标

- sheet 冲突 UI：两侧摘要（表名、行列、合并数）+ 两个动作：用我的 / 用别人的
- 选定即按现有 merge 通道发布整份 workbook JSON
- 不做单元格级决议、不做 merge 拓扑拼装

## 非目标

- 不改 md/html 的 inline merge
- 不在冲突页嵌完整 SheetEditor
- 不改服务端三方算法（sheet 客户端整包二选一即可）

## 验收

- [ ] sheet 冲突不再出现红绿 JSON 行 hunk
- [ ] 「用我的」发布 `localSnapshotContent`；「用别人的」发布远端 head 正文
- [ ] 发布成功后草稿冲突清除、编辑区对齐新 head
