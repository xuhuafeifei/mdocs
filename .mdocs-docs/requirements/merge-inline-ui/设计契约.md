# merge-inline-ui — 设计契约

> **状态**：已同意（2026-08-13）  
> 依据：[`需求分析.md`](./需求分析.md)

## 方案摘要

| 项 | 约定 |
|----|------|
| 布局 | 单栏；去掉左 local / 右 remote 主栏 |
| 段展示 | unchanged 连续；conflict：红 `localLines` + 绿 `remoteLines` |
| 接收 | `resolution = "remote"` |
| 拒绝 | `resolution = "local"` |
| 全部用我的 | 所有 conflict → `local` |
| 全部用别人的 | 所有 conflict → `remote` |
| 编辑 | `unresolvedCount > 0` 只读 inline；`=== 0` 后 textarea 绑组装结果 |
| 完成 | 仍 `convert` + `updateDocument` merge payload；算法 `buildThreeWayMergePlan` 不变 |
| 不做 | both / manual 入口；diff 态手改 |

```text
加载 local/base/remote MD → buildThreeWayMergePlan
→ inline 审阅（接收/拒绝）
→ 全决议 → 可编辑 assembleMergedMarkdown
→ mergeComplete 发布
```

## 变更触达

| 文件 | 改动说明 |
|------|----------|
| `src/web/app/MergeView.tsx` | 去掉左右栏；挂 inline 壳 + 全决议后编辑 |
| `src/web/app/merge/MergeInlinePane.tsx`（新） | 单栏 hunk UI |
| `src/web/app/merge.css` / `App.css` | inline 样式；可复用帮写红绿类名或平行一套 |
| `src/web/i18n/locales/*.ts` | 接收/拒绝/全部用我的/别人的文案 |
| `.mdocs-docs/map/frontend.md` | 关键词增厚 |

`MergeResultEditor` / 侧栏 `MergeCodeMirrorPane`：本增量 UI 不再使用（可留文件，下线入口）。

## 风险与回滚

| 风险 | 缓解 |
|------|------|
| 用户要对照全文 | 接受；需要时再加「高级对照」 |
| both/manual 旧决议 | UI 不再产生；assemble 仍兼容旧 resolution 类型 |
| 回滚 | 恢复三栏 MergeView |

## 测试要点

- 有冲突：接收/拒绝更新 unresolved 计数。
- 全部用我的 / 别人的后可完成。
- 未清完不能完成、不能改正文。
- 清完后改字再发布成功。
