# 设计契约：Agent MCP Client（远程 Memorix）

> 状态：**已同意** · 一期仅 HTTP transport

## 配置

文件：`{dataDir}/mcp-servers.json`

```ts
{
  servers: Array<{
    id: string;
    name: string;
    enabled: boolean;
    transport: "http";
    url: string;                 // e.g. http://host:3211/mcp
    headers?: Record<string, string>;
  }>
}
```

## API

| 方法 | 路径 | 行为 |
|------|------|------|
| GET | `/api/mcp-servers` | 读配置 |
| PUT | `/api/mcp-servers` | 整表替换 `servers` |
| POST | `/api/mcp-servers/:id/test` | 连接并 `listTools`，返回摘要 |

鉴权：同其它 `/api`（visitor token）；写操作任意已认证访客可改（与 server-settings 一致）。

## Agent

每轮 `runOnboardingChat`：

1. `createToolsForMode`
2. 对每个 `enabled` HTTP server：Streamable HTTP 连接 → listTools → wrap 为 `AgentTool`
3. 工具名：`mcp__{slug}__{originalName}`（slug 来自 name/id 净化）
4. parameters：`Type.Unsafe(inputSchema)`；execute → `callTool`
5. 单 server 失败：跳过 + 日志，不整轮失败
6. run 结束 / abort：`close` 所有 client

system prompt：若本轮挂上了 MCP 工具，追加一句可用记忆工具 search/store。

## UI

- 设置 → **MCP 服务器**（独立 Tab，通用列表）：启用、名称、URL、Headers JSON、测试。不提供某个产品的专用模板。
- 产品安装入口见 [`../plugin-marketplace/`](../plugin-marketplace/)：装 Memorix 会在本机安装并启动，再 upsert 本配置。
