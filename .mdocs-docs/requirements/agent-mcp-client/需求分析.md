# agent-mcp-client — 需求分析

> 状态：**已同意**（计划落地）· 一期 MCP Client + 远程 Memorix

## 一句话

mdocs 助手不自建 session memory search；通过 **MCP Client** 接入远程 Memorix（HTTP），配置界面管理服务器列表。

## 背景

- 现有：文档搜、session JSONL、context compact（摘要压缩，非可检索记忆）。
- 目标：记忆外包到运营方服务器上的 Memorix。

## 范围

| 做 | 不做（一期） |
|----|--------------|
| HTTP MCP Client | mdocs 对外 MCP Server |
| dataDir 通用 MCP 配置 + 独立设置页 | 在 MCP 设置页做 Memorix 专用表单 |
| Agent 挂载远程 tools | 自建 session 向量库 |
| 测试连接 listTools | 改 compact 写 Memorix |

## 验收

1. 配置 Memorix URL → 测试连接列出工具。
2. 助手可调 search/store，时间线可见 `MCP · …`。
3. 禁用配置后工具消失。
4. Memorix 不可达不拖死整轮聊天。
