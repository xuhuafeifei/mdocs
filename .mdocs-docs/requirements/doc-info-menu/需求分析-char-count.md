# doc-info-menu / 字符统计 — 需求分析

> 一句话：文档信息菜单异步展示文章**总字符数**（与现有「大小」字节并列）。

## 背景

文档信息下拉已有创建者 / 创建时间 / **大小（Blob 字节）** / 上次编辑。需要再看到正文体量（字数感），且大文档不要卡开菜单。

## 目标

1. 菜单元信息区新增一行：**字符数**（总字符数量）。  
2. **异步**计算：打开菜单先占位，算完再填，不阻塞首帧。  
3. md / html 编辑器菜单都展示。

## 非目标

- 词数 / 中英分词 / 阅读时长  
- 服务端持久化字段、按字符计费  
- 替换现有「大小」（字节仍保留）

## 验收

1. 打开文档信息可见「字符数」；大文打开菜单不长期卡死。  
2. 编辑后再次打开，数字随当前正文更新（以打开时采样为准）。  
3. 中英 UI 有对应文案。

## 字符定义（已与产品对齐，详见设计契约）

人读正文纯字符（「写了多少字」）；**忽略 md 语法**；html 去标签。不是 JSON/源码体积。
