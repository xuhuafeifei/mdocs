# doc-info-menu / 字符统计 — 设计契约

> **状态**：已同意（2026-10-10）

## 方案摘要

在文档信息菜单元信息区、「大小」与「上次编辑」之间（或大小下方）增加一行：

| 标签 | 值 |
|------|-----|
| 字符数 / Characters | 异步填入的整数；计算中显示 `…` |

### 字符定义（本期拍板）

**目的：回答「这篇文章写了多少字」——只计人读正文，忽略 Markdown 语法记号。**

**总字符数 = 去语法后的纯文本** 的 JS `.length`（UTF-16 码元；含汉字、字母、数字、标点与空白，**不**再单独剔标点）。

| 文档类型 | 取样与去语法 |
|----------|----------------|
| md（Lexical） | 打开菜单时取当前正文 → **纯文本**（优先编辑器/Lexical 抽纯文本；或 markdown 再剥语法）。**不计** `#` `*` `` ` `` `[]()` 等语法字符本身；**不计** Lexical JSON 结构 |
| html | 打开菜单时取当前 html → **DOM/去标签后的 textContent** 再 `.length`（不计标签与属性） |

去 Markdown 语法的约定（实现可选 remark 或等价轻量剥壳，结果须接近「预览里看到的字」）：

- 去掉标题/粗斜体/代码围栏标记、链接目标 URL、图片语法等结构性记号  
- 保留链接可见文案、代码块/行内代码中的**正文**、列表项文字  
- meta2d / 特殊围栏：本期可只计围栏内可见文本或整块忽略——**默认：围栏内非语法文本计入，JSON 图数据不计入**（若难区分，整块 `meta2` 围栏不计）

不含：顶栏标题 displayName、评论、附件名。  
空白文 / 去语法后为空：`0`。

### 异步

- 触发：菜单从关→开，或 documentId / 内容世代变化后再次打开。  
- 实现：`queueMicrotask` 或 `requestIdleCallback`（无则 `setTimeout(0)`）里算；结果写 state；关闭菜单可 ignore 过期结果（generation 计数）。  
- 不请求服务端。

### i18n

| Key | zh | en |
|-----|----|----|
| `docInfoCharCount` | 字符数 | Characters |

数值可本地化千分位（可选，非必须）。

## 风险与回滚

| 风险 | 缓解 |
|------|------|
| 超大文卡主线程 | 异步延后；只在打开菜单时算一次 |
| Lexical 导出慢 | 仅打开菜单触发；超时仍显示 `…` 可接受本期 |

回滚：删菜单行与 i18n。

## 测试要点

1. 空文 → `0`。  
2. `# 标题` + 一段正文 → 计数 ≈ 标题字+正文，**不含** `#` 与多余标记。  
3. `[文案](https://x.com)` → 只计「文案」，不计 URL。  
4. 打开菜单后改文再开，数字更新；快速开关不因过期回调写错。
