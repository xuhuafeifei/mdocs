# UI 视觉体系 — 需求分析

> 一句话：统一 mdocs 主界面的**色彩、层级与控件语言**，解决"色彩杂乱、控件风格冲突、空间拥挤"。
> 状态：**已同意**（2026-09-13）· 已落地。

## 背景

前期功能迭代快，视觉是逐处补的，积累出三类问题：

1. **高饱和色滥用**：选中项用绿色底 + 绿色边框；次要按钮（收藏、评论）用绿色描边 `secondary` 类，与主操作抢注意力
2. **层级不清**：侧边栏与主内容区同为白色，只靠 1px 细线分隔；弹框 `z-index` 低于手机端侧边栏抽屉，**弹框被侧边栏盖住**
3. **控件语言不统一**：编辑/预览是两颗实心按钮；图谱工具栏按钮平铺无主次（另见 `knowledge-graph`）

## 目标

1. **降噪**：全站主品牌色仅用于主操作（CTA）、选中指示条、焦点态
2. **建层级**：侧边栏与内容区用背景深浅区分；弹框必须在所有常驻层之上
3. **统一控件**：次要操作用 ghost 样式；分段/开关类控件统一为 iOS 风格浅色分段控制器

## 非目标（本次不做）

- 暗色主题（`color-scheme` 仍固定 `light`）
- 更换品牌主色（沿用绿色 `--mdocs-accent: #4CAF50`）
- 响应式断点体系重构（沿用既有 `max-width: 768px` / `min-width: 769px`）
- 图标库替换

## 验收

1. 侧边栏选中项：浅灰底 `#f2f3f5` + 左侧 3px 绿色指示条，**无绿色边框、无绿色底**
2. 侧边栏背景 `#fafafa`、主内容区 `#ffffff`，肉眼可辨层次
3. 树行内边距 `6px 12px`，行间有呼吸感
4. 顶栏次要按钮（收藏、评论）为 ghost：无边框、灰色图标，hover 出浅灰底
5. **手机端展开侧边栏抽屉时，任何弹框仍完整显示在最上层**（不被抽屉遮挡）
6. 空白状态有引导：大号低透明度图标 + 文案 + 主操作按钮
7. 图谱工具栏符合 [`knowledge-graph`](../knowledge-graph/设计契约.md) 的分区契约
