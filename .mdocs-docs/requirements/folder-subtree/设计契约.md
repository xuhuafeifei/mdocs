# 按目录取子树 — 设计契约

> **状态**：已同意（2026-08-11）并实现  
> 依据：[`需求分析.md`](./需求分析.md)

## 方案摘要

新增 **`GET /api/documents/folder/:folderId/tree`**：

- 入参：仅路径参数 `folderId`（目录行的 `document_id`）
- 出参：精简嵌套树（与整域 `/api/tree` 同构语义，字段更少）
- 权限：域可进 + 节点可读；不可见裁剪
- 实现：复用树构建逻辑（按 `parent_id` 闭包或 path 前缀取子集 → 建树 → 投影为精简 DTO）

## 响应形状

```ts
type FolderSubtreeNode =
  | {
      type: "folder";
      id: string;       // document_id
      title: string;    // folderDisplayName ?? 路径末段
      children: FolderSubtreeNode[];
    }
  | {
      type: "document";
      id: string;       // document_id
      title: string;    // displayName（空则回退文件名）
    };
```

`{ data: FolderSubtreeNode[] }` —— **该目录的直接子树根列表**（不含 `folderId` 自身节点）。

### 标题规则

| type | title |
|------|--------|
| document | `display_name`；空则用 `relative_path` 文件名（去 `.md` 与否与现网树一致） |
| folder | 优先挂载的 `desc.md` 的 `display_name`（现网 `folderDisplayName`）；否则文件夹名（路径末段） |

`___desc___.md` / `desc.md`：**不**作为独立 `document` 叶子出现在子树里（与 `/api/tree` 一致，挂到父 folder 的展示名即可）。

## 错误与空结果

| 情况 | 行为 |
|------|------|
| `folderId` 不存在 | `404` `DOC_NOT_FOUND` |
| 存在但 `file_type !== 'dir'` | `400` `BAD_REQUEST`（不是目录） |
| 域不可进 / 对目录无读权限 | `404` 或空数组——**与 `listFolderChildren` 对齐**（现网 children 对无权限返回 `[]`；若保持一致则 tree 也返回 `{ data: [] }`，避免探测。契约默认：**对齐 children → 无权限/不可见给 `[]`**；仅「存在且为文件」给 400；「完全不存在」给 404） |

待实现时读 `listFolderChildren` 再钉死：不存在 vs 无权限是否都 `[]`。若 children 对不存在也是 `[]`，则 tree 同样，仅「是文件不是目录」返回 400。

## 与现网关系

| 接口 | 关系 |
|------|------|
| `GET /api/tree?domainId=` | 整域；本接口是目录作用域子树 |
| `GET /api/documents/folder/:folderId/children` | 一层扁平；本接口递归嵌套精简字段 |
| 共享 `TreeNode` | **可不直接复用**前端 `TreeNode`（字段更多）；服务端可先建完整树再 map 成精简 DTO，或新建 `FolderSubtreeNode` |

## 风险与回滚

| 风险 | 缓解 |
|------|------|
| 深目录一次过大 | P0 接受；P1 再加 depth/分页 |
| 与 children 错误语义不一致 | 单测对齐；文档写明 |
| 路由被 `/:documentId` 吃掉 | 静态段 `/folder/...` 已存在，并列注册即可 |

## 测试要点

- 空目录 → `data: []`
- 一层：文件夹 + 文档混合，type 正确，title 正确
- 多层嵌套结构正确

- 文章 id 传入 → 400
- 无读权限节点不出现在结果中
