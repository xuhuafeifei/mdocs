# 需求分析：插件市场

## 背景

Agent 可通过 HTTP MCP 接入外部能力（如 Memorix）。产品入口应是「插件」，底层仍是 MCP 配置。

## 目标（一期）

- 设置页独立 **插件市场** Tab。
- 内置目录以 **Memorix** 为安装样板：安装 = 本机 `npm install -g` 并 `memorix background start`，成功后再写入 MCP 项。
- **MCP 服务器** 是独立设置页，只做通用 HTTP 配置（URL / headers / 测试），没有 Memorix 专用按钮。

## 非目标

- 远程插件包下载、签名校验、stdio 插件。
