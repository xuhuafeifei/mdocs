# 需求分析：插件市场

## 背景

Agent 可通过 HTTP MCP 接入外部能力（如 Memorix）。产品入口应是「插件」，底层仍是 MCP 配置。

## 目标（一期）

- 设置页独立 **插件市场** Tab。
- 内置目录主推 **Engram**：安装 = 从 GitHub Releases 下载二进制，写入 stdio MCP（`engram mcp`）。
- **Memorix** 仍可作为可选样板：`npm install -g` + HTTP MCP。
- **MCP 服务器** 是独立设置页：通用 HTTP / stdio 配置与测试，无产品专用按钮。

## 非目标

- 远程任意插件包签名校验、通用插件商店托管。
