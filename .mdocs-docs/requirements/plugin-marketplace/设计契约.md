# 设计契约：插件市场

> 状态：**已同意** · 一期仅内置 Memorix（本机安装并启动）

## 存储

- `{dataDir}/plugins.json`：`{ installed: [{ id, installedAt, mcpServerId? }] }`
- 安装 Memorix：`npm install -g memorix`，`memorix background start`，健康检查 `http://127.0.0.1:3211/health`，再 upsert `{dataDir}/mcp-servers.json`（稳定 id：`plugin-memorix`，URL 固定为本机）。卸载则 `background stop` + `npm uninstall -g memorix` 并删掉该 MCP 项。

## API

| 方法 | 路径 | 行为 |
|------|------|------|
| GET | `/api/plugins` | 目录 + 安装态 + 关联 mcpServer |
| POST | `/api/plugins/:id/install` | 立刻 `202 { job }`。`npm install -g` 使用 npmmirror（`https://registry.npmmirror.com`）。stdout/stderr 追加到 `dataDir/task-logs/plugin-<id>.log`（与图谱任务同一 JSONL）。页面轮询 `installJob.logs`，`done` 才算成功 |
| POST | `/api/plugins/:id/uninstall` | 清安装态并删除对应 MCP 项 |

## UI

- 设置 → **插件市场**（独立 Tab）：安装 / 卸载，不在这里填 Memorix 地址
- 设置 → **MCP 服务器**（独立 Tab）：通用 HTTP 配置
