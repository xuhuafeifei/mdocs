# recent-doc-tabs — 设计契约

> **状态**：已同意（2026-10-23）；工作台三钮 + 吸附（同日）

## 方案摘要

### 最近标签（PC）

| 项 | 约定 |
|----|------|
| 定位 | 挂在各编辑器 **DocChrome（发布栏）下方** 的 `.mdocs-editor-body-host` |
| 钉住 | 默认 **钉住常驻**；未钉 = 吸附条（~8px），悬停覆盖展开；偏好 `mdocs.workbench.tabsPinned` |
| 右侧三钮 | **大纲** · **Lobe** · **钉子**（顺序）；大纲/Lobe 仅 md |
| Lobe | 默认 **关**；`mdocs.workbench.lobeToolbar`；开则显示格式工具栏（不再依赖工具栏内大纲） |
| 大纲 | 默认关；标签栏开关打 `OutlineProvider`；偏好 `mdocs.workbench.outline` |
| 分屏 | 上/下栏各一份标签列表（`mdocs.recentTabs.v2`）；下栏清空 → 收合分屏；上栏清空且有下栏 → 升格 |
| 手机 | **不渲染** |
| 数据 | primary/secondary 稳定顺序；打开不重排；同 id 不同时在两栏 |

### 回顶

| 项 | 约定 |
|----|------|
| 触发 | scrollTop > 240 |
| 范围 | PC + 窄屏 |
