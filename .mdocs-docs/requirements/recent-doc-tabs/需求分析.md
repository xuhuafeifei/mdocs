# recent-doc-tabs — 需求分析

> **状态**：已同意（2026-10-23）；含 **回顶按钮** 同批

## 目标

PC 维护「最近打开」文档标签条：相对主工作区顶缘覆盖式常驻（非整窗 fixed）；用 padding 预留叠层高度，不进正文 flex 流、不遮挡文章管理栏/工具栏；点击已打开文不改变相对顺序；手机端不展示。  
文档滚到下方时提供「回到顶端」按钮（PC / 手机均可）。

## 非目标

- 标签 = 分屏第二栏  
- 跨设备同步最近列表  
- 浏览器级多标签进程隔离  

## 验收

- PC：标签常驻可见；覆盖式 + 等高 padding；点标签切换不重排；× 悬停出现；不遮挡管理栏/工具栏 
- 窄屏：无标签条  
- 滚动超过阈值出现回顶；点击滚到顶
