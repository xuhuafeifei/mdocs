# 工作空间文案与开始写作 — 需求分析

> 一句话：产品概念从「域」改成「工作空间」；实现名仍是 domain。空态只留「开始写作」和「AI 帮写」，不再教新建文件夹。

## 背景

新用户看不懂「域」。空态同时给「新建文档 / 新建文件夹 / AI 帮写」，文件夹也不是他们要先学会的概念。

## 目标

- 界面、助手、文档站、CLI 说明，对人说「工作空间」。
- 库表、接口字段、错误码、CLI 参数继续叫 domain。
- 个人空间库存名仍以「个人域」结尾，只在展示时换成「个人工作空间」。
- 未打开文档时：主按钮「开始写作」（现有新建文档弹窗），旁边保留「AI 帮写」。
- 侧栏、树右键不再提供新建文件夹。

## 非目标（本期不做）

- 不重命名 `domainId`、表、API、错误码、`--domain`、`domains`。
- 不改写历史契约和更新日志正文。
- 不改用户已经手填的工作空间名称。
- 不删已有文件夹，不删后端建目录接口，不删助手 `create_folder`。
- 不改窄屏隐藏「AI 帮写」。
- 不改权限规则（公开 / 受限 / 私有）。

## 验收标准

- 中文界面不再把隔离单元叫做「域」。公网「域名」除外。英文用 Workspace。
- 空态主按钮是「开始写作」，点击后仍是新建文档弹窗。
- 空态在非窄屏、非演示模式仍有「AI 帮写」；窄屏没有。
- 欢迎页、侧栏、树右键都没有「新建文件夹」。
- 库存名以「个人域」结尾的项，界面显示成「…个人工作空间」。
- 文档站概念页标题是「工作空间」，URL 仍是 `/docs/core-concepts/domain`。
