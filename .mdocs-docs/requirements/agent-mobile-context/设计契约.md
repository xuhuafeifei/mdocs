# agent-mobile-context — 设计契约

> **状态**：已同意（2026-08-14）  
> 依据：[`需求分析.md`](./需求分析.md)  
> 补充：reference **不**做权限校验；读正文由 tool 自校验。注入 **system**，不塞 user prompt；不预拉全文。

## 方案摘要

### A. 手机全屏 / 不可拖

| 项 | 约定 |
|----|------|
| 断点 | 与阅读壳相同：`useIsNarrowViewport`（≤768）→ `isNarrow` |
| 面板 | `isNarrow` 时 `.mdocs-agent-panel--fullscreen`：`inset:0`；宽高 100%；无圆角；忽略 `anchorStyle` |
| FAB | `isNarrow` 时固定默认角（如左下），**禁用 pointer 拖动**；点击仍开关面板；隐藏「重置位置」 |
| PC | 保持现有拖动 + `agentPanelAnchorStyle` |

### B. UI 上下文 → reference

| 项 | 约定 |
|----|------|
| 来源 | `App`：`currentDomainId`、`activeDocMeta?.documentId`（未打开文则 `documentId` 省略） |
| 传入 | `AgentChatPanel` props：`domainId?`、`documentId?` |
| 发送 | `streamAgentChatApi` body 增加：`references?: { domainId?: string; documentId?: string }` |
| 时机 | **每轮** Ask（`mode=normal`）发送；有值才带字段 |
| UI | 可不做复杂标签；可选在面板头展示「当前域 / 当前文」只读一行（本增量建议做简一行，避免用户不知道已挂上下文） |

### C. 后端注入上下文

| 项 | 约定 |
|----|------|
| 入参 | `POST /api/agent/chat` 解析 `references`；校验字符串 trim；非法忽略 |
| 权限 | **不做** reference 权限校验；读正文时由 tool 自行校验 |
| 注入方式 | system 追加「当前 UI 上下文」：仅客户端传来的 `domainId` / `documentId`，**不查库、不塞全文** |
| 行为指引 | system 中写明：用户未另指目标时，优先针对该域/该文调用工具；改正文仍走 `overwrite_document` |
| coding | 忽略本字段（仍用现有 `documentId` / workingMarkdown） |

```text
App(isNarrow, domainId, documentId)
  → AgentFab(no-drag) + AgentChatPanel(fullscreen)
  → POST /chat { message, references: { domainId, documentId? } }
  → runOnboardingChat → systemPrompt + Current UI context
```

## 变更触达

| 文件 | 改动 |
|------|------|
| `AgentFab.tsx` / `App.tsx` | 窄屏禁拖、固定位 |
| `AgentChatPanel.tsx` / `App.css` | 全屏 class；props；发 references |
| `endpoints.ts` | `streamAgentChatApi` body |
| `agent.routes.ts` / `run.ts` / `system-prompt.ts` | 解析 references、拼上下文 |
| `tools-documents` 或现有 read | 仅复用查 meta，不新开 tool |

## 风险

- 上下文漂移：用户切文后下一轮才更新 reference（可接受；每轮读 props）
- token：只注入 id + 短 meta，不注入全文
