# agent-mobile-context — 需求分析

> **状态**：已同意（2026-08-14）  
> 日期：2026-08-14

## 背景

手机阅读壳下，智能助手仍是贴 FAB 旁的小浮层，可拖动，阅读空间浪费。Ask 模式发消息时也不带当前域 / 当前打开文章，模型不知道用户「人在哪」。

## 范围

| 做 | 不做 |
|----|------|
| 手机（≤768 / reader）Agent **面板铺满全屏** | 改帮写全屏工作台布局 |
| 手机 **禁止拖动** FAB；面板不跟 FAB 锚点 | 改 PC 可拖 FAB / 旁侧浮层 |
| 每轮 chat 带上 **当前 domainId + 当前 documentId**（有则）作 **reference**，后端注入上下文 | 自动把全文塞进 prompt（只注入 id + 必要元信息，正文仍靠 tool 读） |
| normal（Ask）模式默认带上述 reference | coding 模式已有 documentId，本需求不改帮写协议 |

## 验收

- [ ] 手机打开助手：面板占满视口；无法拖 FAB 改位置
- [ ] PC：行为与现网一致（可拖、旁侧浮层）
- [ ] Ask 发消息 body 含 `references: { domainId?, documentId? }`（与当前 UI 状态一致；无打开文则可不带 documentId）
- [ ] 后端将该 reference 写入本轮上下文，模型可知「当前域 / 当前文」并优先用 tool 读该文
