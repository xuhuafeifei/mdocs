# Sheet 合并单元格与样式 — 需求分析

> 一句话：在现有 `.sheet` JSON 网格上增加 **合并区** 与 **单元格/字体样式**，编辑器可渲染与编辑，Agent 可 patch。

## 背景

当前模型只有「列 + 行 + 纯字符串值」，UI 一格一 input。用户需要合并单元格、底色、字体色/粗体等，用于账本类表格的视觉分组。

## 目标

1. **数据模型**：网格仍按 `(rowId, columnId)` 存值；叠加 `merges[]` 与 per-cell `style`。
2. **兼容**：旧文件（`cells[colId] = "text"`）打开后自动升级为 `{ v }`；无 style/merge 时行为与现在一致。
3. **编辑器**：渲染底色/字体；合并区用 `colspan`/`rowspan`；工具栏可设样式与合并/拆分（基于当前选区）。
4. **Agent**：`sheet_set_cell_style`、`sheet_merge_cells`、`sheet_unmerge_cells`；写操作仍直接发服务端。

## 非目标（本期不做）

- 条件格式、主题色板库、边框线样式全集
- 列宽/行高持久化
- 公式引擎
- 真 Excel `.xlsx` 导入导出中的 merge/style 往返
- 换 Handsontable / Univer 等重型表格引擎

## 验收标准

- [ ] 旧 `.sheet` 无 style/merge 仍可打开、编辑、发布。
- [ ] 设 `bg` / `color` / `bold` / `italic` / `fontSize` 后刷新或重开仍在。
- [ ] 合并 2×2 区：只显示主格，编辑主格值；拆分后恢复独立格。
- [ ] 删除行/列时，触及的 merge 被收缩或删除，不留下悬空引用。
- [ ] Agent 可设置样式与合并，前端收到刷新后可见。
