# Sheet 合并单元格与样式 — 设计契约

> **状态**：已同意（2026-10-10）。

## 方案摘要

| 项 | 约定 |
|----|------|
| 版本 | 保持 `version: 2`；新增字段可选，解析时归一化 |
| 值 | `cells[colId]` 统一为 `SheetCell = { v: string; style?: SheetCellStyle }`；磁盘可读旧 string，写出时可用紧凑形式（无 style 时写 string，有 style 写对象） |
| 样式字段 | `bg?`、`color?`（字体色）、`bold?`、`italic?`、`fontSize?`（px，12–24） |
| 合并 | `tab.merges?: SheetMerge[]`，范围用 **rowId/colId**（不用行列下标，避免插入后错位） |
| 主格 | merge 左上角（`startRowId`×`startColId`）存值与样式；覆盖格仍保留在 `cells` 中但不渲染，值以主格为准 |
| 删除行/列 | 过滤非法 merge；部分重叠则删除整段 merge（简单策略，避免复杂收缩 bug） |
| UI 选区 | 记录 `anchor` + `focus` 两个 `(rowId,colId)`；单格选中也可设样式 |
| 工具栏 | 加粗 / 斜体 / 字号 / 字体色 / 底色；合并选区 / 拆分（点在合并区内） |
| Agent | 见下；与其它 sheet 写一样 `updateDocument` 乐观锁 |
| 颜色 | CSS 色值字符串，限制 `#RGB` / `#RRGGBB` / 空=清除；禁止 `url(` 等 |

## 数据形状（示意）

```json
{
  "version": 2,
  "sheets": [{
    "id": "s1",
    "name": "Sheet1",
    "columns": [{ "id": "c1", "name": "A" }, { "id": "c2", "name": "B" }],
    "rows": [{
      "id": "r1",
      "cells": {
        "c1": { "v": "标题", "style": { "bg": "#E8F5E9", "bold": true, "color": "#2E7D32" } },
        "c2": ""
      }
    }],
    "merges": [{
      "startRowId": "r1", "startColId": "c1",
      "endRowId": "r1", "endColId": "c2"
    }]
  }],
  "activeSheetId": "s1"
}
```

共享 API（拟增）：

- `getCellValue` / `setSheetCell`（只改 `v`，保留 style）
- `setSheetCellStyle(tab, rowId, colId, patch | null)` — `null` 或空对象清样式
- `mergeSheetCells(tab, range)` / `unmergeSheetCells(tab, rowId, colId)`
- `findMergeAt` / `isCoveredCell`（渲染用）
- 改 `sheetRowAsNamedCells` / Agent list 仍只暴露 **字符串值**；schema 可读可选返回 style 摘要

## Agent 工具

| 工具 | 作用 |
|------|------|
| `sheet_set_cell_style` | `documentId`、可选 `sheet`、`cells: [{rowId, column, style}]`；`style` 可局部 patch，传 `null` 清除 |
| `sheet_merge_cells` | `startRowId/startCol` + `endRowId/endCol`（列可用名） |
| `sheet_unmerge_cells` | 任给合并区内一格 `(rowId, column)` 拆掉该 merge |

冲突：新 merge 与已有 merge 重叠 → 失败不写。

## 风险

| 风险 | 处理 |
|------|------|
| 大文件 JSON 变胖 | style 仅非默认时写出；无 style 可仍写 string |
| 选区 UX 简陋 | 本期单击+Shift 点第二格；不做拖拽框选 |
| Agent 乱写颜色 | 校验 hex；非法跳过并记 errors |
| 合并后 Agent 写 covered 格 | `setSheetCell` 重定向到主格或报错——**定稿：重定向写主格并 warning** |

## 测试要点

- string cells 解析 → `{v}`；serialize 无 style 可回写 string
- merge 2×2 渲染只 1 个 td；unmerge 恢复
- 删列碰到 merge → merge 删除
- set style 保留原 `v`
- Agent style/merge 工具单测
