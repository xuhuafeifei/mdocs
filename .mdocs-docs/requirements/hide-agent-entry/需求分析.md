# 隐藏 AI 入口 — 需求分析

> 一句话：通用设置可隐藏右下角智能助手入口；助手可通过 tool 把自己关掉；偏好存 localStorage。

## 背景

用户有时不想看到右下角 AI 浮球（分心 / 演示 / 临时清屏）。希望：

1. 在**设置 → 通用**里手动开关；
2. 对话中让 AI **用 tool 把自己入口关掉**（关完入口消失，当前面板也关掉）；
3. 偏好只在本机，**不进服务端**。

## 目标

- 通用 Tab 增加「隐藏 AI 入口」开关（默认关 = 入口可见）。
- 偏好键：`mdocs.agentEntryHidden`（localStorage，布尔）。
- 隐藏后：不渲染 `AgentFab`；若面板开着则关闭；贴左态一并退出可见入口。
- Agent 工具 `hide_agent_entry`：成功后经 SSE 通知前端写 localStorage + 关面板。
- 恢复路径：设置 → 通用 → 关掉「隐藏」；设置入口本身不受影响。

## 非目标（本期不做）

- 不隐藏「帮写」工作台入口、插件编排入口、设置里的「智能助手」Tab。
- 不把偏好同步到服务端 / 跨设备。
- 不做快捷键临时唤出（除非后续另开需求）。
- 不禁用 `/api/agent/*`（仅 UI 入口；有 URL/设置仍可配模型）。

## 验收

| # | 场景 | 期望 |
|---|------|------|
| 1 | 通用开关打开「隐藏」 | FAB 立刻消失；开着的助手面板关闭 |
| 2 | 刷新后 | 仍隐藏（localStorage） |
| 3 | 通用开关关闭「隐藏」 | FAB 恢复 |
| 4 | 对话中 AI 调 `hide_agent_entry` | 入口隐藏 + 面板关闭；本轮可先说完再关或关完结束 |
| 5 | 隐藏后仍可进设置 → 通用 / 智能助手 | 可恢复、可改模型 |
| 6 | 默认新访客 | 入口可见 |

## 已确认

1. **范围**：只藏主助手入口（`AgentFab` / 贴左）；不藏帮写、插件编排、设置 Tab。
2. **Tool**：仅 `hide_agent_entry`（单向）；恢复走设置 → 通用。
