# 隐藏 AI 入口 — 设计契约

> 状态：**已同意 / 已实现（2026-11-20）**。单向 hide；仅主助手 FAB；恢复走设置 → 通用。

## 方案摘要

| 项 | 约定 |
|----|------|
| 存储 | `localStorage["mdocs.agentEntryHidden"]`，`"true"` / `"false"`；缺省 = 可见 |
| UI | 设置 → **通用** 增加开关，样式对齐 `autoEdit` |
| 入口 | 隐藏时不渲染 `AgentFab`；`agentPanelOpen` 强制收起；贴左布局退出 |
| Tool | `hide_agent_entry`（无参）；挂 `utilityTools`（Ask / 帮写都可用） |
| 前后端 | Tool 发 SSE `agent_entry_hidden`；前端写 LS + 关面板（服务端不存偏好） |
| 恢复 | **仅**设置 → 通用；**不提供** show / set 双向 tool（藏死后模型无法再被唤起开入口） |

## 行为细节

### 设置开关

- 读：`getBool("mdocs.agentEntryHidden", false)`（与现有 Settings 布尔习惯一致）。
- 写：`localStorage.setItem("mdocs.agentEntryHidden", String(hidden))`。
- 打开隐藏：同步 `setAgentPanelOpen(false)`、取消 fullscreen / dock 可见态（与关面板一致）。
- i18n：`hideAgentEntry` / `hideAgentEntryDesc`（中英）。

### App 壳

- `agentEntryHidden` state 从 LS 初始化；监听设置变更（同页 toggle 直接 setState；跨组件可用自定义事件或 props 回调——设置在 App 内 lazy，优先：Settings 回调 `onAgentEntryHiddenChange`，或 `storage` 事件 + 同页直接写）。
- 推荐：`App` 持有 state；`SettingsPage` 增加可选回调 `onAgentEntryHiddenChange?(hidden: boolean)`；开关与 tool 效果都走同一 `applyAgentEntryHidden(hidden)`。
- 渲染：`!agentEntryHidden && !agentDockLayout` 才挂 `AgentFab`；`agentEntryHidden` 时即使 dock 也不再展示助手列入口（关闭 open）。

### Agent Tool

```
name: hide_agent_entry
label: 隐藏 AI 入口
description: 隐藏本机右下角智能助手入口并关闭当前面板。偏好写入浏览器 localStorage。
  仅在用户明确要求隐藏/关掉助手入口时调用。恢复须用户到「设置 → 通用」。
parameters: {}
```

执行：

1. `onEvent({ type: "agent_entry_hidden" })`
2. `asToolResult({ status: "hidden", message: "已隐藏 AI 入口；可在设置 → 通用恢复" })`

前端 `AgentChatPanel` 处理该 SSE：

1. 调 `onAgentEntryHidden?.()`（App 实现：写 LS + setState + `onClose()`）
2. 不阻塞本轮剩余文本（若模型先说话再调 tool，按现有 SSE 顺序即可）

### 系统提示（轻量）

在 Ask system prompt 工具说明里加一句：用户要求隐藏/关掉助手入口时用 `hide_agent_entry`；禁止擅自调用。

## 风险 / 边界

- **藏死后只能靠设置恢复**——可接受；设置入口不依赖 FAB。
- Tool 只 hide、不 show：避免模型误把入口又打开；用户手动恢复更稳。
- 帮写 / 插件台入口**不在本期范围**（见需求分析待确认 #1）。

## 已拍板

1. **Tool 单向 hide**：不提供 show；理由：入口藏了之后无法再调 tool 开启。
2. **范围**：仅主助手 FAB / 贴左助手入口；**不藏**帮写、插件编排、设置里的「智能助手」Tab。
