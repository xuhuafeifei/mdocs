## 完成标准（总）

1. 业务代码只调 `modules/access/access.ts` 的 **id 门面**（及将来的批量门面）；不传 Row / `DomainAccessInfo`
2. 编排在 `application/`；拼装在 `mapper/`；`service` 薄封装；`application` **不** `import` Database
3. 登录鉴权是 Nest **Guard** + 白名单；不再靠 middleware 做强制登录
4. ADR / 活备注与代码现状一致
