# 搜索语义索引 — 代码索引

> 所属需求：`search-embedding`（已同意 2026-09-30）

## 本补丁坐标

| 路径 | 符号 | 说明 |
|------|------|------|
| `src/server/search/embedding-model.ts` | `ensureLocalEmbeddingModel` `embedText` `isEmbeddingReady` | GGUF 下载/load/embed；目录 `MDOCS_EMBEDDING_DIR` 或 `~/.fgbg/shared/embedding/` |
| `src/server/search/embedding-store.ts` | `upsertDocumentEmbeddings` `querySemanticNeighbors` `chunkPlainText` | 切块、BLOB 存向量、JS cosine 近邻（无 sqlite-vec） |
| `src/server/search/document-index-manager.ts` | `rebuildDocument` `removeIndex` `backfillMissingEmbeddings` `extractLexicalPlainText` | FTS 后尽力写向量；删除清 chunk；模型就绪补扫 |
| `src/server/search/search.service.ts` | `searchDocuments`（async） | FTS 合并后 try 语义并入；`matchSource?` |
| `src/server/db/schema.ts` | `document_embedding_chunks` | PK `(document_id, chunk_index)` + embedding BLOB |
| `src/server/app.ts` | `ensureLocalEmbeddingModel()` | 与 `startIndexTimer` 同启，不挡 listen |
| `src/server/documents/document.service.ts` | `scheduleFtsIfNeeded` | nextTick FTS 后 `upsertDocumentEmbeddings` |
| `src/server/routes/documents.routes.ts` | `POST /search` | await `searchDocuments` |
| `src/server/search/embedding-admin.ts` | `listEmbeddingIndex` `rebuildEmbeddingIndex` | 设置页勾选重建；列表含 `embeddingUpdatedAt` |
| `src/web/app/EmbeddingIndexPanel.tsx` | — | 设置「语义索引」Tab |
| `src/server/agent/Agent/tools-documents.ts` | `searchDocumentsTool` | 同上 |
| `package.json` | `node-llama-cpp` | native；失败则语义整路 disable |
