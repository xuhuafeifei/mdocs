# agent-chat-ui-polish — 需求分析

> 一句话：把 mdocs 智能助手面板的**视觉与节奏**拉近 Lobe Chat（轻壳、少框、输入区浮感），**不改**会话协议、工具、SSE、技能逻辑。

## 背景

- 助手壳已有：浮层 / 贴左 / 全屏、气泡、工具折叠、thinking、composer、圆环诊断等（见 `map/frontend.md`）。
- 观感仍偏「卡片堆叠」：工具块边框重、消息间距碎、顶栏/输入区层级不够干净。
- 本会话要求参考 Lobe Chat 气质做一轮抛光；Cursor 旧会话里相关的是表情包页手机适配、提示词弹窗去字噪——**不在本期**（已有契约或已落地）。

## 目标

1. 打开助手面板时，第一眼更像聊天产品，而不是工具调试台。
2. 用户气泡 / 助手正文 / 工具调用 / 输入区 四级分明、噪音更少。
3. PC 浮层、贴左、手机全屏三种壳**同一套 token**，不各写一套皮肤。

## 非目标（本期不做）

- 不重写 `AgentChatPanel.tsx` 结构，不拆巨文件。
- 不改 SSE / session / skill / meme / DiffHunk / choice card 业务行为。
- 不上暗色主题、不换品牌主色（仍跟 `ui-visual-system` + 现有 `#3370ff` 助手强调色）。
- 不做「像 Cursor 侧边 Agent」那种新布局产品。

## 验收标准

- [ ] 浮层 / 贴左 / 全屏打开助手，顶栏更轻、消息区更透气、composer 更像底部输入岛。
- [ ] 工具调用默认态视觉更「胶囊/弱卡片」；进行中仍可辨；错误仍红得清楚。
- [ ] 用户气泡、助手无底正文、复制按钮 hover 仍可用。
- [ ] 手机全屏无横向溢出；贴左不出现双边框「双框」感。
- [ ] 无新增 i18n key（除非文案必须改；本期默认零文案）。

## 依据

- map：`.mdocs-docs/map/frontend.md`（Agent PC 贴左 / 选择卡吸底 / 视觉体系 z-index）
- decisions / 需求：`ui-visual-system`、`agent-dock-left`
- 待确认：是否接受「助手消息继续无气泡底」（Lobe 常见）vs 「浅灰底」——设计契约默认前者（与现状一致，只调字号/间距）。
