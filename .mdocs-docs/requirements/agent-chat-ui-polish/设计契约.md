# agent-chat-ui-polish — 设计契约

> **状态**：已同意（2026-11-11）  
> 未经「已同意」不得开始写业务代码。

## 方案摘要

**CSS-first 抛光**：对齐 Lobe Chat 的聊天壳气质——轻顶栏、透气时间线、弱化工具框、底部输入岛。几乎只动 `App.css` 里 `.mdocs-agent-*`；`AgentChatPanel.tsx` 仅在「缺 class / 包一层」时允许 ≤10 行级改动。

继承 `ui-visual-system`：选中浅灰+指示条、ghost 次要控件、z-index 序不动（agent 面板仍 201）。

### 视觉原则（对照 Lobe Chat）

| 原则 | 落到 mdocs |
|------|------------|
| 少边框 | 工具块默认无重边框 → 浅底 + 细边或无边；去掉「框中框」 |
| 助手少气泡 | 保持助手 `background: transparent`；只调字号/行高/段距 |
| 用户软气泡 | 保留右对齐浅蓝底；圆角更匀（接近 16px），边框更淡 |
| 输入岛 | composer 上边距加大、圆角 18–20、focus 环更轻；与消息列表用留白分隔，而非再加分割线 |
| 顶栏静音 | header 去强渐变；icon 按钮统一 ghost 声量 |
| 时间线节奏 | 消息 `gap` 略增；同轮 tool→text 更紧 |

### 非目标再强调

不改 API、不改历史回放、不改工具折叠交互语义（仍 details/summary）、不动 meme/mermaid/choice 逻辑。

## 变更触达

| 文件 | 改动说明 |
|------|----------|
| `src/web/app/App.css` | 主战场：header / messages / bubble / tool-call / think / input-wrap / welcome chips；必要时加少量 CSS 变量挂在 `.mdocs-agent-panel` |
| `src/web/app/AgentChatPanel.tsx` | **尽量不动**；仅当需要补 wrapper class（例如 footer 区）时 ≤10 行 |
| `.mdocs-docs/map/frontend.md` | 落地后补一条「助手 UI 抛光」关键词入口 |
| `.mdocs-docs/requirements/README.md` | 登记本需求状态 |

### 具体 CSS 落点（验收对照）

1. **Panel 壳**（`.mdocs-agent-panel`）  
   - 浮层：圆角维持 ~18；阴影略收（少「厚投影」）。  
   - `--embedded` / fullscreen：继续无圆角无阴影；避免与 dock 列再叠 1px 边。

2. **Header**（`.mdocs-agent-panel-header`）  
   - 背景改纯 `#fff` 或极淡灰；底部分割线更淡（`rgba(0,0,0,.04)`）。  
   - `.mdocs-agent-panel-icon-btn` hover 统一浅灰底，去掉偏蓝的 hover（保留 active 可辨）。

3. **Messages**（`.mdocs-agent-panel-messages` / `.mdocs-agent-panel-msg*`）  
   - `gap: 18px` → `22px` 左右。  
   - 用户气泡：`border-radius: 16px`；`border` 更淡或去掉；padding `10px 14px`。  
   - 助手：维持透明；Markdown 段距略收紧（`.mdocs-agent-panel-md`）。  
   - 头像：略缩到 28px，降低视觉抢戏。

4. **Tool / Think**（`.mdocs-agent-tool-call*` / `.mdocs-agent-panel-think-fold`）  
   - 默认态：背景 `#f7f8fa`、边框 `transparent` 或 1px 极淡；padding 略减。  
   - running：保留蓝点 pulse，背景 `#f5f7ff`，边框可无。  
   - done 折叠行：字色更灰、字重 500，更像 Lobe「工具一行」。  
   - think 标签继续 shimmer，不换交互。

5. **Composer**（`.mdocs-agent-panel-input-wrap`）  
   - `margin` / 外圈 padding：与消息区拉开（底部「岛」感）。  
   - `border-radius: 18px`；默认边框更淡；`focus-within` 用 2px soft ring，勿过粗。  
   - 发送钮保持现主色，不改行为。

6. **Welcome**（`.mdocs-agent-panel-welcome` / chips）  
   - chip 圆角与字重贴近 composer；hover 浅灰，勿绿块。

### 明确不改

| 区域 | 原因 |
|------|------|
| `SystemPromptDialog` / 圆环逻辑 | 另有 `agent-prompt-inspector` |
| 设置页表情包 | `agent-memes` / 旧会话手机适配另案 |
| z-index 表 | `ui-visual-system` 已定 |
| JobPanel / 编辑器 Alert 未提交改动 | 无关本需求 |

## 风险与回滚

- **风险**：只改 CSS 可能让贴左/手机某处间距挤爆 → 验收三种壳各扫一眼。  
- **回滚**：还原 `App.css` 中 `.mdocs-agent-*` 相关 hunk 即可。
