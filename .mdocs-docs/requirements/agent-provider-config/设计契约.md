# Agent 提供方配置扩展 — 设计契约

> **状态**：已同意（2026-08-26）
> 母需求：`onboarding-ai`（助手 / 帮写 LLM）。本文覆盖 **访客级 LLM 配置两条线**。

## 方案摘要

| 概念 | 约定 |
|------|------|
| 配置线 `kind` | **仅 UI / 保存校验**：`deepseek` \| `custom`；决定表单展示与 PUT 时填哪些字段 |
| 存储 | **一行一套完整字段**，DeepSeek 与自定义 **同表同列**；DS 线的 baseUrl / apiType / providerId 等 **写入 DB**，不在运行时写死 |
| 运行时 | **无 kind 分支**：`getVisitorAgentConfig` → `createAgentModel(cfg)` 只读 `baseUrl、apiType、modelId、apiKey、contextWindow`（+ 可选 compat） |
| 一人一配 | 每访客 **多条** 配置；`is_default=1` 标记默认（每访客至多一条） |

原则：**保存时分叉（预设模板 vs 手填），使用时不分叉。**

---

## 表字段（统一形状）

每条配置 **始终** 具备：

| 列 | 说明 |
|----|------|
| `kind` | `deepseek` \| `custom` — 仅元数据，**运行时不用** |
| `provider_id` | **选填**；技术标识；自定义线 UI 优先展示 |
| `base_url` | **必填落库** |
| `api_type` | `openai-completions` \| `anthropic-messages` |
| `model_id` | 模型 ID |
| `api_key` | 密钥（本期 SQLite；读写抽象） |
| `context_window` | 默认 128000 |
| `is_default` | `0/1`；默认配置供助手 / 帮写使用，每访客唯一 |
| `name` | 配置备注（「张三的配置」） |
| `compat_json` | 可选；OpenAI-compat 微调；空则 pi 按 baseUrl 自动推断 |

> **不使用 `display_name`**：供应商展示由 `kind` + `provider_id` + `name` 推导（DeepSeek 固定展示 Deepseek；自定义优先 providerId，否则配置名称）。

## 两条配置线（仅保存 / UI）

### 线 A：`kind = deepseek`（默认入口）

用户界面只填：**API Key、modelId（flash/pro 下拉）**。

**服务端 PUT 时套用 DeepSeek 预设模板并整行写入 DB**（用户未传的字段由模板填充，不依赖运行时常量）：

| 字段 | 预设值（写入 DB） |
|------|-------------------|
| `provider_id` | `NULL` |
| `base_url` | `https://api.deepseek.com` |
| `api_type` | `openai-completions` |
| `compat_json` | DeepSeek 已知 compat 快照（如 `supportsDeveloperRole: false` 等） |

### 线 B：`kind = custom`

用户填：**baseUrl、apiType、modelId、apiKey**；**providerId 选填**。

| 字段 | 规则 |
|------|------|
| `provider_id` | **选填**；若填则 `[a-z][a-z0-9_-]*` |
| `base_url` | 必填；`https://`；trim 尾随 `/` |
| `api_type` | 必填 |
| `model_id` | 必填非空 |
| `compat_json` | 可选；v1 UI 不暴露则 NULL |

v1 **不**做：模型目录、discoverModels。

### 切换 kind

从 custom → deepseek：PUT `kind=deepseek` 时 **用预设模板覆盖** provider/baseUrl/apiType/compat（保留 apiKey、modelId 若在校验白名单内否则重置为 flash 默认）。

从 deepseek → custom：PUT `kind=custom` 时要求用户提交完整 custom 字段（或保留已有 custom 字段若曾切换过）。

## 类型（示意）

```ts
export type AgentConfigKind = 'deepseek' | 'custom'; // 仅 API / UI
export type AgentApiType = 'openai-completions' | 'anthropic-messages';

export type VisitorAgentConfig = {
  id: string;
  ownerVisitorId: string;
  kind: AgentConfigKind;      // 元数据，createAgentModel 不读
  providerId: string | null;  // 选填
  name: string;               // 配置备注
  baseUrl: string;            // 始终有值
  apiType: AgentApiType;
  modelId: string;
  apiKey: string;
  contextWindow: number;
  compat: OpenAICompletionsCompat | null;
};
```

## API

### `GET /api/agent/configs`

返回当前访客全部配置（含 `isDefault`）。

### `GET /api/agent/config`

返回 **默认** 配置（助手 / 帮写 / 内嵌表单用）。

### `PUT /api/agent/config`

body 可含 `id`（有则更新，无则新建）、`isDefault`（新建时可设为默认）。

### `POST /api/agent/config/:id/default`

将指定配置设为默认。

### `DELETE /api/agent/config/:id`

删除指定配置；若删的是默认项，自动提升另一条。

**DeepSeek 线** — body 可只含：

```json
{
  "kind": "deepseek",
  "modelId": "deepseek-v4-flash",
  "apiKey": "sk-…",
  "name": "可选备注",
  "contextWindow": 128000
}
```

服务端 **merge 预设模板** 后 upsert 全行（含 `base_url` 等）。

**自定义线** — 示例：

```json
{
  "kind": "custom",
  "providerId": "acme-gateway",
  "baseUrl": "https://gateway.example/v1",
  "apiType": "openai-completions",
  "modelId": "my-model",
  "apiKey": "sk-…"
}
```

`providerId` 可省略。

校验：`invalid_provider_id` | `invalid_base_url` | `model_id_required` | …

## 运行时（统一，无 kind 分支）

```ts
// config.ts — 读库即完整 cfg，endpoint 来自 base_url 列
export function getVisitorAgentConfig(visitorId: string): VisitorAgentConfig | null;
export function agentProviderLabel(cfg): string; // deepseek → Deepseek；custom → providerId ?? name

// run.ts — 唯一入口
function createAgentModel(cfg: VisitorAgentConfig) {
  const model = {
    id: cfg.modelId,
    baseUrl: cfg.baseUrl,
    api: cfg.apiType,
    contextWindow: cfg.contextWindow,
    compat: cfg.compat ?? undefined,
    // ...
  };
  // 仅按 cfg.apiType 选 openAICompletionsApi / anthropicMessagesApi
  // 禁止 if (cfg.kind === 'deepseek')
}
```

`getAgentStatus`：`enabled` = 有 apiKey && skillsReady；可返回 `kind` / `modelId` / `providerId` 供 UI。

DeepSeek 预设常量 **`DEEPSEEK_PRESET`** 只出现在 **upsert 模板**（config.ts 或 routes），不出现在 `run.ts`。

## 前端

- 配置 **列表**：每条可「设为默认」（单选）、编辑、删除
- 新建时可选「保存后设为默认」；首条配置自动为默认
- 线 A / B 为 **新建/编辑表单** 的类型，不再互斥覆盖同一行
- 删除默认项时，自动把另一条提升为默认
