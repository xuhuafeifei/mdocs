# agent-get-editor-draft — 设计契约

> **状态**：已同意（2026-10-23）  
> **方案**：按需 tool；SSE 通知前端立刻取稿（不征求意见）；`requestId` 关联等待前端 POST 回传。  
> **不做**：CLI `ai-merge`（浏览器草稿 CLI 读不到；远程部署更读不到）

## 澄清

### 「等待」≠ 征求意见

| 含义 | 做不做 |
|------|--------|
| 出卡 / 让用户点允许 | **不做** |
| 前端收到 SSE **立刻自动**取稿并 POST | **做** |
| 服务端用 `requestId` await 回传 | **做**（技术关联，否则 tool 无正文） |

### CLI merge：干掉

浏览器草稿只在 IndexedDB。CLI `--file` 读的是跑 CLI 那台机的磁盘，**不是**访客草稿；服务端部署时更无关。  
因此 **不提供** `ai-merge` CLI；合并浏览器草稿只走：Web Merge UI，或 Agent（`get_editor_draft` → merge tools）。

### 链路

```
Agent 调 get_editor_draft
  → 服务端登记 requestId 并 await
  → SSE editor_draft_request
  → 前端自动取编辑器/IDB → MD/HTML
  → POST /api/agent/editor-draft { requestId, content, … }
  → tool result 交给 LLM
  →（可选）suggest_document_merge(localContent=…)
```

## 方案摘要

### Tool

`get_editor_draft`

| 项 | 约定 |
|----|------|
| 参数 | `documentId?`（缺省 UI `references.documentId`） |
| 行为 | SSE 通知 → **前端自动执行** → POST 回传 → tool 返回 |
| 超时 | 默认 **30s**；run abort 则取消等待 |
| 正文格式 | **仅** `markdown` / `html` / `plain`，禁止 Lexical JSON |

```ts
// 成功
{
  status: "ok",
  documentId: string,
  content: string,
  contentFormat: "markdown" | "html" | "plain",
  source: "editor" | "indexeddb",
  localBaseCommitId?: string | null,
  displayName?: string,
}
{ status: "unavailable", reason: string }
{ status: "timeout" }
{ status: "cancelled" }
```

### SSE / HTTP

| 方向 | 形状 |
|------|------|
| 下行 | `{ type: "editor_draft_request", requestId, documentId, expiresAt }` |
| 上行 | `POST /api/agent/editor-draft`：`{ requestId, status: "ok"|"unavailable", content?, … }` |

无 `action: cancel` 用户入口（用户不感知）；仅 run 取消 / 超时。

### 前端（强制自动）

收到即执行，**零确认 UI**：

1. `documentId` ≠ 当前焦点 → `unavailable`  
2. sheet → `unavailable`  
3. 优先编辑器内存，否则 IDB  
4. md→Markdown；html→HTML 原文  
5. 立刻 POST；时间线只显示 tool_call「读取本地草稿」

### Agent 编排

- 合并浏览器本地稿：先 `get_editor_draft`，再 `suggest_document_merge` / `suggest_document_merge_message`  
- coding：仍用 `get_working_document`；本 tool **不注册**到 coding

## 测试要点

- 自动回传 ok；未打开文 unavailable；超时；错 visitor  
- 回传非 Lexical  
- normal 注册；coding 不注册  

## 风险

- 大稿占一轮 tool token：按需可接受  
- 切文竞态：documentId 不匹配 → unavailable
