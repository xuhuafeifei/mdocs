# 域权限升级与文章筛选 — 设计契约

> **状态**：已同意（2026-09-18，用户要求按此实现）

## 已定决策

1. **域权限只能升级，不能下降。** 开放程度 `private < restricted < public`。相同值视为成功、不改库。已有文档仍可升级。重命名、删除在有文档时仍锁定。内置 `default` 域仍只有系统创建者能改，普通用户改不了。
2. **我的文章**仍只含当前访客创建的文档。筛选、分组参数都不传时行为与现在相同。
3. Agent 工具走同一套规则，不另开特权。

## 域权限

`PUT /api/domains/:id/permission` 与工具 `set_domain_permission`：

| 变更 | 结果 |
|------|------|
| private → restricted / public，restricted → public | 成功，有文档也行 |
| 更封闭 | 400 `DOMAIN_PERMISSION_DOWNGRADE` |
| 相同 | 200，不写库 |
| 非创建者 | 403 |

界面里下降的选项禁用；已经是 public 时不能再改类型。

## 我的文章

`GET /api/visitors/me/documents`

| 参数 | 不传 |
|------|------|
| `domainId` | 不按域滤 |
| `creatorVisitorId` | 不按创建者再滤（列表本身已是本人的文档） |
| `groupBy` | 不分组。`domain` 或 `creator` 时本页 `groups` |
| `offset` / `limit` | 0 / 20，最大 100 |

每行多 `creatorVisitorId`、`creatorName`。设置页用三个下拉：域、创建者、分组。

## Agent tools

| 工具 | 作用 |
|------|------|
| `set_domain_permission` | 升级域权限 |
| `query_my_documents` | 查询我的文章：可选 `domainId` / `creatorVisitorId` / `groupBy`，以及 `offset` / `limit`（默认 0/20，最大 100） |
| `invite_document_user` | 文档创建者邀请访客。`permission` 为 `read` 或 `edit`，不传则 `read`。域成员不能再被邀请 |
