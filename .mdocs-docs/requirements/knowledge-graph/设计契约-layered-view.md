# 知识图谱可读展示（分层展开）— 设计契约

> **状态**：草案  
> **所属需求**：`knowledge-graph`（增量，改展示层；不改构建 / 存储 schema）  
> 未经「已同意」不得开始写业务代码。

## 方案摘要

全量力导向把 `contains` / `依赖` / `相关` 等同画出 → 人类不可读。  
**数据仍是图**（关系比层级重要不变）；**展示用 `contains` 作导航骨架**，默认只露顶层，按需一层层展开；其它边类型默认隐藏、可叠加。

不做「硬排成静态树」；布局仍可用力导向，但只对**当前可见子图**布局。

## 目标 / 非目标

### 目标

1. 打开目录图谱，第一眼能读懂顶层知识骨架（约十来个以内量级，视数据而定）
2. 用户可按分支下钻，或用快捷按钮统一展开到一级 / 二级
3. 悬停立刻看到节点全名；选中节点仍可看定义 / 来源（既有详情面板）

### 非目标（本期不做）

- 改 `___graph___.json` 结构或后端聚合逻辑
- 一键「展开全部」作为主按钮（可藏进「更多」，非默认）
- 邻域探索（ego）模式、左大纲右子图双栏（可作为后续增量）
- 人工编辑节点 / 边
- 强制定位算法必须是树坐标（`fx`/`fy` 钉死）；允许力导向在可见子图上跑

## 默认视图

| 项 | 规则 |
|----|------|
| 默认深度 | **仅顶层 concept**：在 `contains` 边上入度为 0 的 concept（无父概念） |
| doc 节点 | 默认仍不画在图上（与原契约「默认只显示 concept」一致）；「显示 doc」开关保留 |
| 非 `contains` 边 | **默认不画**（`related_to` / `依赖` 等）；工具栏开关可叠加到**当前可见节点**之间 |
| `contains` 边 | 只画「已展开父 → 已可见子」 |
| 切换目录 | 重置为默认深度（全部收起至顶层） |

顶层定义待实现时若遇环 / 多父：按「`contains` 入度 0」为主；若无入度 0（纯环），降级为「取度数最高的 N 个 concept 作种子」并在 UI 提示——属实现细节，验收以「默认可读」为准。

## 工具栏（全局深度）

| 按钮 | 行为 |
|------|------|
| **展开一级** | 所有**当前已可见**且仍有未展示 `contains` 子节点的节点，各展开其**直接子**一层 |
| **展开到二级** | 从顶层起，使深度 ≤ 2 的 `contains` 子孙全部可见（顶层为深度 0） |
| **全部收起** | 回到默认：仅顶层 |

「展开一级」是相对当前可见集再长一层；「展开到二级」是绝对深度，便于从任意状态一键回到「两层地图」。

不提供主路径上的「展开全部」。

## 节点交互（局部）

| 操作 | 行为 |
|------|------|
| **单击节点** | **选中** + 打开 / 更新右侧详情面板（定义、来源、子节点列表） |
| **展开** | 节点旁 **`+` / 展开角标**（有未展示子节点时显示）；点击后展开该节点的直接 `contains` 子节点 |
| **收起** | 角标变为 `−`（或等价）；收起该节点下已展开的子孙（仅影响该分支） |
| **悬停** | **立刻**显示全名（CSS/`data-tooltip` 类即时提示，不用浏览器原生 `title` 延迟） |

详情面板内「包含的子节点」列表：点击某子节点 = 选中该子；若图上尚未可见，则先展开到该子再选中。

## 可见子图与布局

1. 前端维护 `expandedIds: Set<nodeId>`（表示「该节点的直接子已展开」）；默认空 = 只显示顶层。
2. 可见节点 = 顶层 ∪ 所有 `expanded` 祖先路径上的 `contains` 子孙。
3. 可见边 = 两端均可见，且（类型为 `contains` 或用户已打开的边类型开关）。
4. 将可见 nodes/edges 交给 `react-force-graph-2d`；切换展开状态后允许短暂 reheat，不必钉死树坐标。

## 与原契约的关系

- 原 [`设计契约.md`](./设计契约.md)「默认力导向 + 点节点出详情 + 默认隐藏 doc」仍成立。
- 本增量**修正**「一次渲染全图」的隐含假设：全量数据仍加载，**渲染集**按展开状态裁剪。
- 原「关系比层级重要」不变：非层级边仍在数据中，用开关进入视野，不靠删数据。

## 风险与回滚

| 风险 | 应对 |
|------|------|
| 顶层仍过多（>30） | 后续可加置信度 / 度数截断；本期可先做 + 搜索定位 |
| 用户找不到「依赖」边 | 边类型开关默认关但可见；空态文案提示「打开依赖/相关」 |
| 展开后局部仍乱 | 可见集变大时属预期；引导用收起 / 只展分支 |

回滚：前端恢复「全 concept + 全边」渲染即可，无数据迁移。
