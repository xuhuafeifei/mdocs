# Agent 聊天 Mermaid 渲染 — 需求分析

> 状态：已同意（2026-09-10）

## 背景

Ask / 帮写助手回复可用 ` ```mermaid ` 围栏，但 `AgentChatPanel` 的 `AgentMarkdown` 仅用 `ReactMarkdown` + GFM，围栏只当代码块，不画图。文档编辑器（lobe）侧已支持 Mermaid；聊天侧缺预览。

## 目标

Agent 聊天里的 mermaid 围栏：**默认渲染成图**，用户可切换为**代码模式**（并保留复制）。持久化仅源码，SVG 不落库。

## 非目标

- 不改 lobe 主编辑器 / Meta2d / Markmap
- 不强制帮写工作台同步做所见即所得（可复用组件，本期以 Agent 聊天气泡为准）
- 不持久化每个块的「图/码」偏好（会话内状态即可）
- 服务端不预渲染、不存储 SVG

## 验收

1. 助手消息中合法 mermaid 围栏默认显示 SVG/图，而非仅源码
2. 块上可切换「图谱 ↔ 代码」；切到代码后行为与现有代码块一致（可复制）
3. 非法 / 渲染失败时有可读错误，并可切到代码看源
4. 流式输出过程中不因半截围栏频繁抛错（稳定后再渲染或失败兜底）
5. 非 mermaid 围栏行为不变
6. 会话/文档只存 mermaid 源码，无服务端 SVG
