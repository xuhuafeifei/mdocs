# Agent 聊天 Mermaid 渲染 — 设计契约

> 状态：**已同意（2026-09-10）** — 服务端不存 SVG，只存 mermaid 源码；展示时前端翻译渲染

## 方案摘要

在 `AgentMarkdown` 的 `pre`/`code` 渲染路径识别 `language-mermaid`（及 `mermaid` class），用独立小组件：

- **默认 `diagram`**：`import('mermaid')` 动态加载，对源码 `mermaid.render`，结果插入容器
- **可切 `code`**：复用现有 `MarkdownPreWithCopy` 样式与复制按钮
- 切换控件：块右上角（或工具条）「图谱 / 代码」二态；默认图谱

## 存储原则（已确认）

- **持久化 / 会话消息 / 文档正文**：只保留 Markdown 围栏内的 **mermaid 源码**
- **禁止**服务端把图预渲染成 SVG 再入库或塞进 SSE
- SVG 仅为前端运行时产物；刷新后由源码再次翻译

## 行为细则

1. **识别**：`code` 的 `className` 含 `language-mermaid` / `mermaid` 才走专用块；其余仍走 `MarkdownPreWithCopy`
2. **默认模式**：`diagram`
3. **流式**：源码变化时 debounce（~150–300ms）再 render；卸载时 cancel / 忽略过期 promise
4. **失败**：图区显示简短错误文案；仍可切到代码；不拖垮整条消息
5. **安全**：仅渲染助手/已有消息 Markdown 中的围栏文本；不 `eval`；mermaid 用默认安全配置即可
6. **帮写工作台**：本期不强制；若 `AiWriteWorkbench` 复用同一 `AgentMarkdown`/组件则顺带受益，否则单列 follow-up
7. **图谱交互（已同意增量）**：点击图进入悬浮层；层内可拖动画布、滚轮/按钮缩放；Esc / 点遮罩关闭。仍只基于源码前端渲染，不存 SVG
