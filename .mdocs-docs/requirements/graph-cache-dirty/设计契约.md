# 图谱缓存 dirty — 设计契约

> **状态**：已同意（2026-08-26）
> 母需求：`knowledge-graph`（构建 / 展示）。本文只覆盖**缓存一致性与正文解耦**。

## 方案摘要

| 概念 | 约定 |
|------|------|
| 落盘对象 | 完整 `GraphFile`：`{ version, meta, nodes, edges }` |
| 文章 meta | `{ commitId, dirty }` — `commitId` = **上次成功抽图**时的 commit，不是当前 head |
| 目录/域 meta | `{ dirty }` |
| 构建跳过 | **只看 dirty**（本期不做 sourceHash） |
| 祖先蔓延 | `markAncestorsDirty(parentId)`：从**父目录 id** 起爬 `parent_id`，有 `___graph___` 才置 dirty |
| 与主链路 | 无 event bus；CRUD **先记下 ids，做完正文事后** `setImmediate` 调 graph lifecycle |
| 发布 | 异步变化率；未超阈值不改 `commitId`、不 dirty |

原则：CRUD **只维护缓存脏标 / 删产物**，不修订知识结构；知识只在显式构建时重投影。

```
src/server/documents/
  document.service.ts      # 只：抠 parentId → 删/挪/发布 → scheduleGraphLifecycle(...)
  graph.service.ts         # 读写 GraphFile 的底层帮助函数，供 lifecycle / deps 用
```

**没有** event bus。可选极薄调度：

```ts
// graph/lifecycle.ts
export function scheduleGraphLifecycle(task: () => Promise<void>): void {
  setImmediate(() => {
    void task().catch((err) => {
      console.warn("[graph-lifecycle]", err);
    });
  });
}
```

## 核心 API 骨架（你要看的「代码怎么写」）

### 1. 变化率（纯函数，易单测）

```ts
// graph/change-ratio.ts
/** ratio = (added + removed) / max(oldLines, 1) */
export function changeRatio(oldText: string, newText: string): number {
  const a = oldText.split("\n");
  const b = newText.split("\n");
  // 行级 LCS 或简单 diff 统计增删行数
  const { added, removed } = lineEditCounts(a, b);
  return (added + removed) / Math.max(a.length, 1);
}

export const DEFAULT_GRAPH_DIRTY_RATIO = 0.15;
```

### 2. mark：只吃 parentId（或 domain）

```ts
// graph/lifecycle.ts
/** 从 folderId 自身开始标 dirty，再沿 parent_id 向上；最后域图 */
export async function markAncestorsDirty(params: {
  domainId: string;
  folderId: string | null; // 文章的 parent_id；null 表示直接脏域图
}): Promise<void> {
  let p: string | null = params.folderId;
  while (p != null) {
    const file = await readDirGraphFile(p); // 无文件 → skip
    if (file) {
      file.meta.dirty = true;
      await writeDirGraphFile(p, file);
    }
    const row = findDocumentById(getDb(), p);
    p = row?.parent_id ?? null;
  }
  const domainFile = await readDomainGraphFile(params.domainId);
  if (domainFile) {
    domainFile.meta.dirty = true;
    await writeDomainGraphFile(params.domainId, domainFile);
  }
}
```

### 3. 删文 / 移文 / 发布 — lifecycle 入口

```ts
export async function onArticleDeleted(params: {
  domainId: string;
  documentId: string;
  parentId: string | null; // 删之前抠出的
}): Promise<void> {
  await markAncestorsDirty({
    domainId: params.domainId,
    folderId: params.parentId,
  });
  await deleteArticleGraphCache(params.documentId); // DB + 盘
}

export async function onArticleMoved(params: {
  domainId: string;
  documentId: string;
  oldParentId: string | null;
  newParentId: string | null;
}): Promise<void> {
  await markAncestorsDirty({ domainId: params.domainId, folderId: params.oldParentId });
  await markAncestorsDirty({ domainId: params.domainId, folderId: params.newParentId });
  await deleteArticleGraphCache(params.documentId); // 不搬；下次构建惰性创建
}

export async function onArticlePublished(params: {
  domainId: string;
  documentId: string;
  parentId: string | null;
}): Promise<void> {
  const cached = await readArticleGraphFile(params.documentId);
  if (!cached) return;

  const oldLexical = await readCommitLexical(params.documentId, cached.meta.commitId);
  const newLexical = await readCurrentLexical(params.documentId);
  const oldText = extractPlainTextFromLexical(oldLexical);
  const newText = extractPlainTextFromLexical(newLexical);
  const ratio = changeRatio(oldText, newText);
  if (ratio < DEFAULT_GRAPH_DIRTY_RATIO) return;

  cached.meta.dirty = true;
  // 注意：不更新 commitId
  await writeArticleGraphFile(params.documentId, cached);
  await markAncestorsDirty({
    domainId: params.domainId,
    folderId: params.parentId,
  });
}
```

### 5. 构建侧（index.ts）

```ts
async function buildDocumentGraph(documentId: string, deps: GraphDeps): Promise<Graph> {
  const cached = await deps.readArticleGraphFile(documentId);
  if (cached && cached.meta.dirty === false) {
    return { nodes: cached.nodes, edges: cached.edges };
  }
  // 重提…
  const commitId = await deps.getCurrentCommitId(documentId);
  await deps.writeArticleGraphFile(documentId, {
    version: 1,
    meta: { commitId, dirty: false },
    nodes,
    edges: [],
  });
  return { nodes, edges: [] };
}

async function buildFolderGraph(folder, deps): Promise<Graph> {
  const cached = await deps.readDirGraphFile(folder.documentId);
  if (cached && cached.meta.dirty === false) {
    return { nodes: cached.nodes, edges: cached.edges };
  }
  // 子节点后序 build → aggregateAndInduce → 写回 dirty:false
}
```

`commitId` 不变量：只有**成功重提写回**时更新为当前 head；发布小改与仅标 dirty **不得**改写。

## 明确不做

- event bus
- sourceHash
- 主链路内联隐藏文件 IO
- 移文搬迁 `__graph__/{id}.graph.json`

## 测试要点

- `changeRatio` 边界：空文、只改一行、大段增删
- `markAncestorsDirty`：无目录图跳过该层继续向上；有则 dirty
- 删文：lifecycle 用 parentId，不依赖文章行仍存在
- 发布：无缓存 noop；小 ratio 不 dirty；大 ratio dirty 且 commitId 不变
- 构建：dirty false 跳过 AI；重提后 dirty false 且 commitId 为新 head
- lifecycle throw 不影响 removeDocument 已成功

## 风险

- 异步 mark 失败 → 短暂展示未标脏的旧图；可接受，日志可查；下次强制「重新生成」仍正确
- 阈值误判 → 可调 `DEFAULT_GRAPH_DIRTY_RATIO`
