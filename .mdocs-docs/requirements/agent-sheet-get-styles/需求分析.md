# Agent 读取表格样式 — 需求分析

> 一句话：新增只读工具 `sheet_get_styles`，按格 / 行 / 列 / 整表返回单元格 style；不改动 `sheet_list_rows` 的纯文本返回。

## 背景

样式能力已在 `sheet-merge-style` 落地：磁盘存 `SheetCell.style`（bg / color / bold / italic / fontSize），写可用 `sheet_set_cell_style`。

但读路径故意不带 style：

- `sheetRowAsNamedCells` 只吐 `Record<列名, string>`
- `sheet_list_rows` / `sheet_get_schema` 不返回样式
- 设计契约原文：「Agent list 仍只暴露字符串值」

结果：助手能改样式，却看不到现有样式，无法「照着表头红底再涂一行」这类任务。

## 目标

1. 单独只读工具：只返回 style（不含单元格文本值）。
2. 四种范围：
   - 某一格
   - 某一行每个格子
   - 某一列每个格子
   - 整张工作表
3. 大表不炸 token：整表默认稀疏（只返回有 style 的格）。
4. `sheet_list_rows` 保持只返回文本值（职责分离）。

## 非目标（本期不做）

- 不把 style 塞进 `sheet_list_rows` / `sheet_get_schema`
- 不返回 merges（已有 merge 工具；需要时可另开）
- 不写样式（仍用 `sheet_set_cell_style`）
- 不做 HTTP REST 新接口（仅 Agent tool）

## 验收标准

- [ ] Agent 可调 `sheet_get_styles`，按 scope 拿到对应格子的 `style`
- [ ] 无样式的格在稀疏模式下不出现；单格查询无样式时明确返回 `style: null`
- [ ] 非法 rowId / column → 明确错误，不写库
- [ ] 系统提示指引：查样式用本工具，改样式用 `sheet_set_cell_style`
- [ ] 单测覆盖四档 scope

## 依据

- map：`tools-sheet.ts` / `sheetDocument.ts`（`getCellStyle`、`sheetRowAsNamedCells`）
- decisions / 需求：`.mdocs-docs/requirements/sheet-merge-style/设计契约.md`（刻意不在 list 暴露 style）
- 待确认：整表是否允许 `includeEmpty=true` 拉全量（默认否）
