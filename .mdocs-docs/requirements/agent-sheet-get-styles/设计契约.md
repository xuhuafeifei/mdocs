# Agent 读取表格样式 — 设计契约

> **状态**：已同意（2026-10-20）

## 方案摘要

| 项 | 约定 |
|----|------|
| 工具名 | `sheet_get_styles` |
| 语义 | **只读**返回指定工作表单元格的 `SheetCellStyle`；不含 `v` |
| 范围 | 默认 active 表；可传 `sheet`（表名或 id） |
| scope | `cell` \| `row` \| `column` \| `sheet`（必填） |
| 定位 | `cell`/`row` 要 `rowId`；`cell`/`column` 要 `column`（列名或 columnId） |
| 稀疏 | `sheet` / `row` / `column` 默认只返回 **有 style** 的格；`includeEmpty?: boolean` 为 true 时才补无样式格（`style: null`） |
| 单格 | `scope=cell` 始终返回该格一条；无样式 → `style: null` |
| 上限 | `sheet` 稀疏无硬上限；`includeEmpty=true` 时单元格数 > 5000 → 失败（防爆） |
| 权限 | 同 `sheet_list_rows`：可读即可 |
| 与现有分工 | 值 → `sheet_list_rows`；样式 → 本工具；写样式 → `sheet_set_cell_style` |

## 为何不塞进 list_rows

`sheet-merge-style` 已约定 list 只暴露字符串，避免每行 JSON 膨胀。本期延续该分工，用专用读工具按需取样式。

## 工具契约（给模型）

- **label**：读取表格样式
- **description**：读取 `.sheet` 单元格样式（bg / color / bold / italic / fontSize）。`scope=cell|row|column|sheet`。默认只返回已设置样式的格；单格无样式返回 `style:null`。要单元格文本请用 `sheet_list_rows`；写样式用 `sheet_set_cell_style`。
- **parameters**：
  - `documentId: string`
  - `sheet?: string`
  - `scope: "cell" | "row" | "column" | "sheet"`
  - `rowId?: string`（cell / row 必填）
  - `column?: string`（cell / column 必填；列名或 id）
  - `includeEmpty?: boolean`（默认 false；仅对 row/column/sheet 有意义）
- **返回**：
  ```json
  {
    "documentId": "...",
    "sheet": { "id": "...", "name": "..." },
    "scope": "row",
    "includeEmpty": false,
    "styledCount": 2,
    "cells": [
      { "rowId": "r1", "column": "金额", "columnId": "c2", "style": { "bg": "#E8F5E9", "bold": true } }
    ]
  }
  ```
  - `column` 用**列名**（与 set 工具对称）；另带 `columnId` 防重名歧义
  - `style` 为归一化后的对象；无样式且 includeEmpty/单格 → `null`

## 共享层（可选小函数）

在 `sheetDocument.ts` 增加只读收集，避免 tool 内手写遍历：

- `collectSheetCellStyles(tab, opts)` → `{ cells, styledCount }`
- 覆盖格（merge covered）仍按其自身 `cells[colId].style` 返回（与磁盘一致；UI 主格优先渲染不在本期改语义）

## 风险与回滚

| 风险 | 处理 |
|------|------|
| 整表 includeEmpty 爆 token | 默认稀疏；includeEmpty 硬上限 5000 |
| 助手仍去 list_rows 找 style | system-prompt 写清分工 |
| 列名重复 | 返回同时带 columnId；解析沿用 `resolveSheetColumn` |

## 测试要点

- 给三格上样式 → `scope=sheet` 只返回这三格
- `scope=row` + 指定 rowId → 仅该行有样式的格
- `scope=column` → 仅该列
- `scope=cell` 无样式 → `{ style: null }`
- 未知 rowId / column → throw
- `includeEmpty=true` 小表补齐 null；超大表失败
