# document-trash-ui — 设计契约

> **状态**：已同意（2026-10-21）

## 方案摘要

| 项 | 约定 |
|----|------|
| API | 复用 `GET /documents/deleted`、`POST /documents/restore` |
| 权限 | 原 owner（后端已校验） |
| UI | Settings 侧栏「回收站」；文案：恢复删前最新正文 |
| 分页 | 沿用现网 `limit`；条目少可不加 cursor |

## 变更触达

| 文件 | 改动 |
|------|------|
| `endpoints.ts` | `listDeletedDocumentsApi` / `restoreDocumentApi` |
| `TrashPanel.tsx` 或 Settings 内嵌 | 列表 + 恢复 |
| `SettingsPage.tsx` | 新 tab |
| i18n | 文案 |

## 测试要点

- 列表加载 / 空态 / 恢复成功 / PATH_EXISTS toast
