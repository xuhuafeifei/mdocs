# document-trash-ui — 需求分析

> 一句话：设置页「回收站」列出可恢复删文并一键恢复；复用已有 deleted/restore API。

## 背景

删文 recovery + `GET /deleted` + `POST /restore` 已落地，无前端入口。

## 目标

设置页回收站：列表（标题/路径/时间/可恢复）+ 恢复；冲突 toast。

## 非目标

- audit 流水 / 按文章聚合审计
- 复原整棵 commit DAG（仅 head 正文）
- 目录节点恢复
- 非 owner 可见

## 验收

- 删文后回收站可见；恢复后正文与删前 head 一致
- 路径占用 → 明确错误，不静默改名

## 依据

- `requirements/document-delete-recovery/`
