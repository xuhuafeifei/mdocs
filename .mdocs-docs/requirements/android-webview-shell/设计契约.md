# android-webview-shell — 设计契约

> **状态**：已同意（2026-09-12）  
> 轻量原生 WebView 壳；不上架；用户自填服务器地址。

## 方案摘要

1. **壳 = 系统 WebView 浏览器**，不内置 mdocs 前端。用户填的 URL 就是 `loadUrl` 的地址。
2. 工程放本仓 **`android/`**（Kotlin + Gradle），与 `src/web` 解耦。业务代码零改动。
3. 地址存 App 私有 `SharedPreferences`。无原生顶栏；「更换服务器」用桌面图标长按快捷方式。
4. 允许 **http 明文**（自托管常见）；**https 校验系统证书**；自签证书弹一次「仍要打开」确认。
5. 壳 UI 主色对齐网页 `--mdocs-accent`（`#4CAF50`），不用黑顶栏。
6. 分发：本地 `assembleRelease`（或 Debug）出 APK，文档写安装步骤。不上架。

## 已拍板（相对讨论）

| 项 | 决议 |
|----|------|
| 平台 | **仅 Android** |
| 分发 | **APK 侧载**，不上架 |
| 服务器 | **用户填写**，不写死 |
| 技术 | **原生 WebView**，不用 Capacitor / RN |
| 前端 | **不改** mdocs Web；壳不注入业务 JS |

## 用户流程

```text
启动
  → 无保存 URL：填写页（示例占位 http://192.168.x.x:4000 ）
       校验 http(s) + host → 保存 → loadUrl
  → 有保存 URL：直接 WebView（无原生 Toolbar）
长按桌面图标「更换服务器」→ 填写页（不清空各源站 WebView 存储）
回到前台：读剪贴板；若为已配置源站且含 `/doc/<id>` 或 `#/doc/<id>` → WebView 打开该文
返回键 → WebView.canGoBack ? goBack : 退出
```

填写规则：trim、自动补 `http://`（若用户只写了 host:port）、拒绝非 http(s)。

## WebView 能力

必须开：JavaScript、DOM Storage（localStorage）、第三方 cookie 若涉及。  
必须接：`WebChromeClient.onShowFileChooser`（附件上传）；`DownloadListener` → 系统 DownloadManager（zip/pdf 等 attachment）。  
`usesCleartextTraffic=true`。文件选择走系统文档选择器。

外链：同 host 留在 WebView；其它 http(s) 用系统浏览器（避免壳变成通用浏览器）。

## 风险与回滚

| 风险 | 缓解 |
|------|------|
| 手机访问不到服务器 | 填写页失败提示（WebView 错误回调）；文档写明需局域网/VPN/公网 |
| 自签证书 | 一次确认，不永久关闭校验 |
| WebView 与 Chrome 行为差 | 不宣称 100% 一致；上传/JS 是硬门槛 |
| 换服务器串身份 | 按 origin 隔离 localStorage，不额外清数据 |

回滚：不合并 `android/` 即可，主产品无耦合。

## 测试要点

1. 冷启动无地址 → 填写 → 能打开现网 mdocs
2. 杀进程再开 → 不再填，仍进站
3. 更换服务器 → 加载新 URL
4. 非法输入（空、ftp、无 host）拒绝
5. http IP:端口 可开（cleartext）
6. 返回键先退页再退 App
7. 能选图/文件上传（若该站有上传）
8. 剪贴板为同源 `/doc/<id>`：切回 App 打开该文；其它站点 URL 忽略
