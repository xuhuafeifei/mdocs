# version-history-compare — 需求分析

> 一句话：版本历史弹框里加「并排对比」——左右各一个只读 Lobe 正文，按百分比联动滚动，可全屏；**不做 diff 计算**。

## 背景

现有 [`document-version-restore`](../document-version-restore/设计契约.md) 的版本历史面板（`VersionHistoryPanel.tsx`）是「左侧 commit 列表 + 右侧单栏只读预览」，一次只能看一版。用户想同时看「选中的历史版」和「当前版」，靠人眼对照。

明确**不是**要 Git 式的逐行差异视图：不需要 diff 算法、不需要红绿高亮、不需要行对齐。要的是两块正常渲染的正文，滚动位置按比例绑在一起。

## 目标

1. 版本历史弹框右上增加**全屏**按钮，单栏预览与对比模式都适用。
2. 弹框内增加**并排对比**：在左侧列表里**点名**两个版本——第 1 个进左栏、第 2 个进右栏，行上标出 `左` / `右`；两栏也保留下拉可改/可清空，**允许任一侧为空**。
3. 两栏各自可滚动；**联动开关**控制「按百分比同步」或「各滚各的」。
4. 在原弹框上就地切换形态（不是新开一个弹框）：左侧历史列表压缩为窄栏，可折叠。
5. 头部操作（对比 / 全屏 / 收起列表 / 关闭）用 **SVG 图标 + tooltip**，不占文字宽度。
6. 纯前端；复用现有 `getDocumentCommitApi` 与只读 Lobe 预览插件，**后端零改动**。

## 非目标（本期不做）

| 不做 | 原因 |
|------|------|
| diff 计算 / 差异高亮 / 行级对齐 | 用户明确不需要 |
| `sheet` / `html` 的并排对比 | 现有预览对 sheet 只是文字摘要、html 是 iframe，没有「Lobe」语义；保留单栏 |
| 恢复语义变化 | 仍由「恢复此版本」负责，对比是只读 |
| 手机端并排 | 窄屏两栏不可读，入口隐藏（见待确认） |

## 验收标准

- 打开有 ≥2 个版本的 `.md` →「并排对比」→ 两栏**都为空**，各显示占位；列表提示「点一个版本放进左侧」。
- 点列表第 1 个版本 → 该行出现 `左` 徽标，左栏渲染；提示变「再点一个版本放进右侧」。
- 点第 2 个版本 → 出现 `右` 徽标，右栏渲染；两侧都选好后「联动滚动」可用。
- 再点已选行 → 该侧被摘掉（允许为空），联动自动禁用；`左`/`右` 徽标同步消失。
- 两侧都选好后再点第三行 → 替换左栏（交替规则）。
- 改动任一下拉（含「未选择」）与列表徽标双向同步。
- 默认联动开启：左栏滚到 10%，右栏到 10%（±1px）；两侧未选满时开关置灰。
- 关闭联动：两栏互不影响；开关状态在下次打开时保持。
- 全屏按钮：切换弹框到视口满屏，`Esc` 退出全屏；再次点击还原。
- 只有 1 个版本时「并排对比」不可用（tooltip 提示至少两个版本）。
- `.html` / `.sheet` 文档看不到对比入口；窄屏看不到对比入口。
- 恢复按钮作用于左栏版本；左侧为空时置灰。
- 恢复成功后自动退出对比态并刷新列表。
- 不产生任何 diff 计算请求。

## 待确认

1. 右栏基线取**服务端 head commit**（不含未发布草稿）——默认如此；若想要「编辑器里的实时草稿 vs 历史版」，需要父组件把当前正文传进来。
2. 窄屏（≤768px）：默认**隐藏**对比入口；若要「上下两栏 + 联动」，请说一声。
3. 左侧历史列表在对比态默认**收成 260px 窄栏**（保留可见），可一键折叠为图标条；是否要默认折叠？
