# agent-dock-left — 需求分析

> 一句话：PC 端智能助手可贴左替换文档树，与正文并排，避免反复开关浮层。

## 背景

助手浮层盖住正文，长时间对照阅读/改稿时只能关掉再开。帮写左栏已有 `embedded`，主壳未复用。

## 目标

- PC 增加「贴左」布局：助手占左侧栏位，文档树隐藏，正文全宽可见。
- 贴左栏可拖拽改宽并持久化。
- 贴左时打开文档不关助手。

## 非目标

- 窄屏 / 手机贴左
- 改帮写 workbench
- 关助手后左侧仍占空栏

## 验收

- 浮窗 ↔ 贴左可切换；关闭助手恢复目录
- 拖宽刷新后仍保留；贴左开文助手仍开
- 窄屏无贴左入口
