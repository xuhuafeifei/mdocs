# agent-dock — 需求分析

> 一句话：PC 端智能助手可贴左或贴右与正文并排，避免反复开关浮层。

## 背景

助手浮层盖住正文，长时间对照阅读/改稿时只能关掉再开。帮写左栏已有 `embedded`，主壳已支持贴左；用户还希望能贴右，目录仍留在左侧习惯位置。

## 目标

- PC「贴左」：助手占左侧栏位，文档树移到右侧挤占轨（已实现）。
- PC「贴右」（本期）：助手占右侧栏位，**左侧完整文档树保留**，正文居中。
- 贴边栏可拖拽改宽并持久化（左右共用宽度偏好）。
- 贴边时打开文档不关助手。

## 非目标

- 窄屏 / 手机贴边
- 改帮写 workbench
- 关助手后仍占空栏
- 左右同时贴（互斥）

## 验收

- 浮窗 ↔ 贴左 ↔ 贴右可切换；关闭助手恢复对应目录布局
- 拖宽刷新后仍保留；贴边开文助手仍开
- 窄屏无贴边入口
- 旧 `mdocs.agentDocked=true` 仍当作贴左
