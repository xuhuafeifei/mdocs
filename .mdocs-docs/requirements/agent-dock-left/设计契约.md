# agent-dock-left — 设计契约

> **状态**：已同意（2026-10-21，计划确认后实现）  
> 依据：[`需求分析.md`](./需求分析.md)

## 方案摘要

| 项 | 约定 |
|----|------|
| 范围 | 仅 `!isNarrow` |
| 布局 | 浮窗 / 全屏 / **贴左**（互斥；贴左时退出全屏） |
| 进入 | 标题栏「贴左」→ `mdocs.agentDocked=true`，助手进左列 `embedded` |
| 退出 | 标题栏「浮窗」→ 偏好取消并恢复目录；或关闭（X）→ 关面板并恢复目录（偏好可保留，下次打开仍贴左） |
| 宽度 | `mdocs.agentDockWidth`；默认 360；夹在 `280 … min(560, 45vw)`；右缘拖拽 |
| 开文 | 贴左时 `onOpenDocument` **不**关面板 |
| 单例 | 同时只挂一个 `AgentChatPanel`（浮层或贴左列） |
| FAB | 贴左打开时仍可点关；关闭后按偏好再开 |
| 贴左+目录 | 贴左时 **助手左 · 正文中 · 右侧挤占式纯目录**（无品牌头/新建/访客脚）；浮窗/关闭后目录回左侧完整侧栏 |

### 本次变更（右侧纯目录 · 2026-10-21）

- `agentDockLayout` 时挂 `.mdocs-tree-rail`，仅渲染 `DocumentTree`
- **挤占式**：flex 分宽（默认 240px），与正文抢空间，非覆盖
- **可隐藏 + 动画**：`mdocs.agentTreeRailOpen`（默认开）；收起宽→28px 绿色吸附「目录」条；宽/显隐 cubic-bezier 过渡
- 与左侧完整侧栏互斥（贴左时左列是助手，不是树）
