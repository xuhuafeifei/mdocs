# agent-dock — 设计契约

> **状态**：贴左已实现；**贴右增量已同意 / 已实现（2026-11-20）**。  
> 依据：[`需求分析.md`](./需求分析.md)

## 方案摘要

| 项 | 约定 |
|----|------|
| 范围 | 仅 `!isNarrow` |
| 布局 | 浮窗 / 全屏 / **贴左** / **贴右**（贴边与全屏互斥；贴边时退出全屏） |
| 贴左 | 助手进左列 `embedded`；右侧 `.mdocs-tree-rail` 挤占式目录（已有） |
| 贴右 | 助手进右列 `embedded`；**左侧完整侧栏保留**；不挂 tree-rail |
| 进入 | 标题栏「贴左」/「贴右」→ 写 `mdocs.agentDockSide` |
| 退出 | 「浮窗」→ side 清空；或关面板 → 关开态，偏好可保留 |
| 宽度 | 共用 `mdocs.agentDockWidth`；贴左拖**右**缘，贴右拖**左**缘 |
| 开文 | 贴边时 `onOpenDocument` **不**关面板 |
| 单例 | 同时只挂一个 `AgentChatPanel` |
| FAB | 任一贴边打开时不叠浮球（同现贴左） |

### 偏好迁移

| 键 | 行为 |
|----|------|
| `mdocs.agentDockSide` | `"left"` \| `"right"`；缺省/其他 = 浮窗 |
| `mdocs.agentDocked`（旧） | 读：若无 `agentDockSide` 且旧值为 `"true"` → 视为 `"left"`；写：同步 `agentDocked = (side==="left"\|\|"right")` 以兼容旧逻辑，或逐步只写 side |

推荐 API：

```ts
type AgentDockSide = "left" | "right" | null; // null = float
loadAgentDockSide(): AgentDockSide
saveAgentDockSide(side: AgentDockSide): void
```

`loadAgentDocked()` 可改为 `loadAgentDockSide() !== null` 的薄封装，或内联替换调用点。

### 标题栏控件

浮窗时：

- 「贴左」`PanelLeft`
- 「贴右」`PanelRight`

贴左时：

- 「浮窗」`PanelLeftClose`（或统一「取消贴边」）
- 「贴右」一切到右侧

贴右时：

- 「浮窗」
- 「贴左」

不引入三态循环单钮（易误触）。

### App 布局

```
浮窗:   [ sidebar | main ] + 浮动 AgentChatPanel
贴左:   [ agent-dock | main | tree-rail ]
贴右:   [ sidebar | main | agent-dock ]
```

- `agentDockLayoutLeft` = `side==="left" && open && !narrow`
- `agentDockLayoutRight` = `side==="right" && open && !narrow`
- 右列挂载与左列对称：`.mdocs-agent-dock.mdocs-agent-dock--right`（或复用同一 class，靠 DOM 顺序在 main 后）

### AgentChatPanel

- `docked` → 升级为 `dockSide?: "left" | "right"`（或保留 `docked` + 新增 `dockSide`）
- 贴右：`onResizePointerDown("left")`；贴左仍 `"right"`
- `onToggleDock` 拆成 `onDockLeft` / `onDockRight` / `onUndock`，或 `onSetDockSide(side)`
