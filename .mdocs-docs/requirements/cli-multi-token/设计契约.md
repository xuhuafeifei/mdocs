# cli-multi-token — 设计契约

> **状态**：已同意（2026-10-21）

## 方案摘要

| 项 | 约定 |
|----|------|
| 多活跃 | `createCliToken` **不再** `revokeAll` |
| 停用 | `revoked=1`；`PATCH { revoked: 0\|1 }` 可恢复 |
| 删除 | `DELETE` 物理删行；不可恢复 |
| 列表 | GET 含停用，不含已删 |

## 变更触达

| 文件 | 改动 |
|------|------|
| `cli-token.service.ts` | 去 revokeAll；`setCliTokenRevoked`；`deleteCliToken` |
| `cli-token.repo.ts` | `setRevoked` / `deleteCliToken` |
| `cli-tokens.routes.ts` | PATCH；DELETE 改为硬删 |
| `SettingsPage.tsx` | 多 Token UI |
| `endpoints.ts` | PATCH / DELETE 封装 |

## 测试要点

- 双 Token 并存鉴权
- 停用 / 启用 / 硬删
