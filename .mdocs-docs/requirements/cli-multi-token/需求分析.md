# cli-multi-token — 需求分析

> 一句话：客户端可同时持有多个 CLI Token；每个可单独停用/再启用；硬删除后不可恢复。

## 背景

现网签发会 `revokeAll`，同一访客只能有一个活跃 Token；「吊销」单向，设置页只能「创建或重置」。

## 目标

1. 可同时多个活跃 Token（签发不踢掉旧的）
2. 停用（`revoked=1`）可再启用；硬删除行后明文永远失效
3. 设置页：列表 + 启停 + 删除 + 新建（可命名）

## 非目标

- Token 作用域白名单（`cli-token-scope`）
- Token 过期时间
- CLI Token 请求审计 UI

## 验收标准

- 连续新建两个 Token，两者均可调 API
- 停用后 401；再启用后可用
- 删除后旧明文 401，列表中消失

## 依据

- `map/identity-auth.md` → CLI Token
- 计划：多 Token · 回收站 · 目录移动
