# 中间正文上下分屏 — 设计契约

> **状态**：已实现（2026-10-21）

## 方案摘要

| 项 | 约定 |
|----|------|
| 范围 | 仅 PC `main` 内容区；上下最多 **2** 栏 |
| 类型 | 每栏独立按 `fileType` 挂 `DocumentEditor` / `HtmlEditor` / `SheetEditor` |
| 同文双开 | **禁止**（第二栏打开已在另一栏的 id → toast，不切换） |
| 焦点 | `focusedPane: "primary" \| "secondary"`；点击栏内任意处切换；Agent / URL / 树选中高亮跟焦点栏 |
| URL | 仍只反映焦点文档 `/doc/:id`；下栏文档不进 path（刷新靠 localStorage 恢复 secondary） |
| 比例 | 竖向拖拽条；默认 50/50；`mdocs.editorSplitRatio` ∈ [0.25, 0.75] |
| 开关 | `mdocs.editorSplitOpen`；关闭 secondary 即单栏 |

## 交互

### 打开下栏

1. **树节点右键 / 文档菜单**：「在下方打开」（仅 PC）
2. **修饰键点击**：`⌘`（Mac）/ `Alt`（Win·Linux）+点击树节点 → 打开到下方（已有焦点文档时）；若当前未分屏则开启分屏并把该文放 secondary
3. 从单栏「…」或顶栏入口：「分屏」→ 若无 secondary，提示再点一篇文档，或打开当前工作空间最近一篇（**本期不做自动猜文**，只提供「在下方打开」）

### 关闭

- 下栏顶栏「关闭分屏」→ 卸 secondary，primary 铺满
- 上栏关闭：若有 secondary，secondary **升格**为 primary（避免空上栏）

### 拖拽比例

- 中间水平 `resize handle`（约 4～6px）；拖动改 `splitRatio`
- 双击 handle → 复位 0.5

## 状态模型（App）

```ts
type EditorPaneId = "primary" | "secondary";

// 每栏一套（可抽 hook / 小组件，避免 App 爆炸）
type PaneState = {
  meta: ActiveDocumentMeta | null;
  editorContent: { content: string; displayName: string; contentRevision: number } | null;
  // 既有：editBaseCommitId / draft presence 等按 documentId 已隔离的可共用
};

splitOpen: boolean;          // secondary 是否占用
splitRatio: number;          // primary 高度占比
focusedPane: EditorPaneId;
primary: PaneState;
secondary: PaneState;
```

- **单栏**：`splitOpen === false`，只渲染 `primary`（行为与现状一致）
- **分屏**：`main` 内 `flex-column`：`primary` | handle | `secondary`

## 与现网耦合

| 能力 | 行为 |
|------|------|
| 草稿 / 自动发布 | 仍按 `documentId`；两栏各挂自己的 editor 实例即可 |
| 冲突 Merge | **仅焦点栏**进 MergeView；另一栏保持可编 |
| 帮写 / 评论 | 绑焦点栏文档 |
| Agent `documentId` | 绑焦点栏 |
| 图谱焦点 | 进图谱时建议 **退出分屏或清空 secondary**（一期：清空 secondary + `splitOpen=false`，避免和 graph 主区抢） |
| 贴左助手 | 无冲突：分屏只在 `main` 内 |

## 实现触达（同意后）

| 路径 | 变更 |
|------|------|
| `App.tsx` | pane 状态；`openDocument` 增加 `target?: EditorPaneId`；main 分屏布局 |
| `DocumentTree.tsx` / 菜单 | 「在下方打开」；可选 Alt+click |
| `App.css` | `.mdocs-editor-split*`、resize handle |
| `DocChrome` / 各 Editor | 可选：分屏时略压缩顶栏；关闭按钮 |
| i18n | 相关文案 |
| localStorage | `mdocs.editorSplitOpen` / `mdocs.editorSplitRatio` / `mdocs.editorSplitSecondaryId` |

## 默认拍板（有异议请改）

1. URL 只跟焦点文档；secondary 靠 `editorSplitSecondaryId` 恢复  
2. 禁止同 id 双开  
3. 进图谱清掉分屏  
4. 一期不做「左右分屏」与窄屏
