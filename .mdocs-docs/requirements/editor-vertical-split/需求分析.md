# 中间正文上下分屏 — 需求分析

> 一句话：PC 模式下主内容区可上下两栏同时编辑两篇文档，类型可不同（如上 Lobe / 下 Sheet）。

## 背景

贴左助手后布局为 `左助手 | 中正文 | 右目录`。用户希望**只**在中间正文区再做上下分屏：上下均可编辑，且容器类型不必相同（md / html / sheet 可任意组合）。

## 目标

1. **仅 PC**（`!isNarrow`）：窄屏不做上下分屏。
2. **仅中间栏**：不改左右栏语义；贴左 / 右侧目录与分屏可同时存在。
3. **上下两格皆可编辑**：各自独立草稿、发布、顶栏（或精简顶栏）。
4. **类型可混**：上 `md` + 下 `sheet`、上 `html` + 下 `md` 等均合法。
5. 有明确的「打开到下栏 / 关闭一栏 / 拖拽调比例」入口。

## 非目标（本期不做）

- 左右分屏、三栏编辑区、任意多 pane
- 手机上下分屏
- 同一 `documentId` 双开（禁止，避免双草稿互踩）
- 跨工作空间硬绑分屏状态到服务端（默认只本地记）

## 验收标准

- [ ] PC 可打开第二文档到下栏；上下可同时编辑且类型可不同
- [ ] 窄屏无分屏 UI / 行为
- [ ] 关掉一栏后另一栏铺满；刷新后比例与「是否分屏」可恢复（localStorage）
- [ ] 同文档不可上下双开（有提示）
- [ ] 助手注入的「当前文档」跟随**焦点栏**（最后点击的那一栏）
