# Agent 表格行：append / update / insert_at — 设计契约

> **状态**：已同意。**修订（2026-10-13）**：拆成三个工具，去掉混用的 `upsert` / 万能 `insert_rows`。

## 方案摘要

| 工具 | 语义 |
|------|------|
| `sheet_append_rows` | 表末追加多行 |
| `sheet_update_row` | 按 `rowId` patch 已有行（必填且须存在） |
| `sheet_insert_rows_at` | 插在 `afterRowId` **后面**（必填） |

| 项 | 约定 |
|----|------|
| 行形状 | `{ cells: [{ column, value }] }` |
| 上限 | append / insert_at 单次最多 **100** 行 |
| 列解析 | `resolveSheetColumn`；未知列整批失败 |
| 权限 / 发布 | 同现有 sheet 写 |

共享层：`insertSheetRows`（append 或 `{ afterRowId }`）、`updateSheetRow`。

## 变更触达

| 文件 | 说明 |
|------|------|
| `src/shared/sheetDocument.ts` | `insertSheetRows` / `updateSheetRow` |
| `src/server/agent/Agent/tools-sheet.ts` | 三工具；移除 `sheet_upsert_row` / `sheet_insert_rows` |
| `system-prompt` / `tool-call-ui` / `tools-registry` | 同步 |

## 测试要点

- append → 新行在末尾
- insert_at(afterRowId) → 紧跟该行之后
- update 缺 row / 找不到 → 抛错，不新建
- 未知列 → 整批失败
