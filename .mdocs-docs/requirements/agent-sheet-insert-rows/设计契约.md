# Agent 批量插入表格行 — 设计契约

> **状态**：已同意（2026-10-10）。

## 方案摘要

| 项 | 约定 |
|----|------|
| 工具名 | `sheet_insert_rows` |
| 语义 | **只追加**：每行新建 `rowId`，接到表末；不更新已有行 |
| 入参 | `documentId`；可选 `sheet`（表名或 id）；`rows`（非空数组） |
| 行形状 | 每行 = `{ column, value }[]`（与 `sheet_upsert_row.cells` 同形），或等价的「列键→值」对象二选一——**定稿用 cells 数组列表**，和现有工具一致，模型不易搞混 |
| 上限 | 单次最多 **100** 行（低于 `sheet_set_cells` 的 200，避免一次 payload 过大） |
| 列解析 | `resolveSheetColumn`；任一未知列 → 抛错，整批不写 |
| 空值 | `value` 缺省 / null → `""`；未提到的列 → `""` |
| 权限 / 发布 | 同现有 sheet 写：`edit` + `localBaseCommitId = head`，一次 `updateDocument` |

共享层加 `insertSheetRows(tab, rows[])`：循环复用与 `upsertSheetRow` 相同的列解析，全部成功后再替换 tab。

## 工具契约（给模型）

- **label**：批量插入表格行
- **description**：向指定工作表末尾一次追加多行（Excel 式 `.sheet`）。不改已有行；改已有行用 `sheet_upsert_row` / `sheet_set_cells`。单次最多 100 行。列名或 columnId。写后直接发布。
- **parameters**：
  - `documentId: string`
  - `sheet?: string`
  - `rows: Array<{ cells: Array<{ column: string; value: string }> }>`
- **返回**：`status`、`documentId`、`sheet`、`inserted`（条数）、`rowIds[]`、`rowCount`、`headCommitId`

## 风险与回滚

| 风险 | 处理 |
|------|------|
| 助手仍循环 `upsert_row` | system-prompt 写明「多行用 insert_rows」 |
| 半成功 | 未知列 / 超限在写盘前失败；不部分追加 |
| 超大粘贴 | 硬上限 100；超限提示拆批 |

## 测试要点

- 空表插 3 行 → `rowCount=3`，返回 3 个 `rowId`。
- 已有行后再插 → 新行在末尾，旧 `rowId` 不变。
- `rows` 含未知列名 → 抛错，内容不变。
- `rows.length > 100` → 抛错。
- `rows: []` → 抛错（与 upsert 要求 cells 非空一致）。
