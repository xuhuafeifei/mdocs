# Agent 批量插入表格行 — 需求分析

> 一句话：给智能助手一个工具，一次往 `.sheet`（Excel 式工作簿）指定工作表末尾插入多行，只发一次布。

## 背景

已有 `sheet_upsert_row`：一次只写一行（新建或按 `rowId` patch）。从 CSV / 粘贴 / 列表导入时，助手要循环调用，每次整表发布，慢且容易中途失败留下半截数据。

产品里的表格是 mdocs 的 `.sheet` 工作簿（多标签），不是真 `.xlsx` 文件；用户说的「Excel 表格」指这种表格文档。

## 目标

1. Agent 工具 `sheet_insert_rows`：一次追加多行到指定工作表末尾。
2. 列用列名或 `columnId`（与现有 sheet 工具一致）；缺的列填空串。
3. 单次有行数上限；一次调用只发布一次（一个 head commit）。
4. 系统提示：批量新行用本工具；改已有行仍用 `sheet_upsert_row` / `sheet_set_cells`。

## 非目标（本期不做）

- 按 `rowId` 更新、按某列去重合并
- 导入真 `.xlsx` / `.csv` 文件上传
- UI 粘贴导入
- 改列结构（加列）——未知列名整批失败，不静默丢字段

> **修订**：中间插入已支持（`beforeRowId` / `afterRowId` / `atIndex`），不再列为非目标。

## 验收标准

- [ ] 一次传入 N 行后，表末多出 N 行，返回每行新 `rowId`；文档只多一个新 head。
- [ ] 超过上限 → 明确失败，表不变。
- [ ] 任一字段列名未知 → 整批失败，表不变。
- [ ] 无编辑权 / 非 sheet → 与现有 sheet 写工具同样失败。
- [ ] 指定 `sheet` 或默认 active 表行为与 `sheet_upsert_row` 一致。
