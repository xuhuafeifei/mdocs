# 设计契约：智能助手 Lexical 按块提案（md_format_lexical）

> 状态：**已同意**（会话拍板）· 帮写不动 · 智能助手试点 · mdocs 引用本地 lobe（不 npm 发版）

## 目标

智能助手按外层块读/写提案 → 前端 LexicalDiff 审阅 → Accept/Reject → 拼完整 Lexical 写回编辑器。

## 不变式

- 落盘/编辑器唯一正文：完整 Lexical JSON
- `md_format_lexical`（`Record<"1"|"2"|…, md>`）仅 Agent 往来；门牌临时、用完即弃
- Agent 读 **base**（提案未应用的正式正文）；pending 不进模型
- `LexicalDiff` 只渲染；决策与拼稿在 mdocs
- `patch_lines`：外层块门牌；`replace_all`：整篇新稿，门牌作废，按 diff row 决策
- 新提案覆盖旧提案；应用前可锁编

## API

| Tool / SSE | 行为 |
|------------|------|
| `get_document_lexical_lines` | 读文档 → 外层块 → `{ lines, documentId }` |
| `set_document_lexical_lines` | 不写盘；SSE `lexical_lines_set` 推前端提案 |
| `lexical_lines_set` | `{ documentId, mode, lines?, markdown? }` |

## 写回

用户「应用」：按决策拼 `root.children` → `setDocument(json)`（本地草稿/未发布态与现有编辑器一致）。
