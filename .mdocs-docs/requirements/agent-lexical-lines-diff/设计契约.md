# 设计契约：智能助手 Lexical 按块提案（md_format_lexical）

> 状态：**已同意**（会话拍板）· **增量：原生 DiffHunk 嵌入 DocumentEditor（2026-10-27）** · **增量：slot 四工具对齐 Lobe API（2026-10-27）** · **增量：batch_update_slots 多段连续区间（2026-10-28）** · 帮写不动 · 智能助手试点 · `@lobehub/editor` → `npm:@fgbg/lobe-editor`

## 目标

智能助手按外层块读/写提案 → **live Editor 内** Lobe Diff API（`updateSlot` / `insertAfterSlot` / `removeSlot` / `overwriteAll`）→ 用户 Accept/Reject → 写回同一编辑器。

## 不变式

- 落盘/编辑器唯一正文：完整 Lexical JSON（无 pending DiffHunk）
- `md_format_lexical`（`Record<"1"|"2"|…, md>`）仅 Agent 往来；门牌临时、用完即弃
- Agent 读 **base**（提案未应用的正式正文）；pending 不进模型
- 审阅 UI：`ReactDiffPlugin`（DiffHunk + DiffReviewBar）；**不再**用 LexicalLinesReview 浮层
- `patch_lines` / `replace_all`：前端合成完整 Markdown → `overwriteAll`
- 单槽改/插/删：SSE → 直接调 Lobe `updateSlot` / `insertAfterSlot` / `removeSlot`
- `batch_update_slots`：SSE → 前端按 **base 门牌** 做多段 span 替换 → 合成 MD → **一次** `overwriteAll`（避免多次工具调用互相 Undo All）
- 有 pending 时 `assertCanPublish` 拦截发布；新提案若已有 pending → 先 Undo All 再落地（不拒绝）

## API

| Tool / SSE | 行为 |
|------------|------|
| `get_document_lexical_lines` | 读文档 → 外层块 → `{ lines, documentId }` |
| `set_document_lexical_lines` | 不写盘；SSE `lexical_lines_set` → `proposalToMarkdown` → `overwriteAll` |
| `update_slot` | SSE `diff_slot_op` → `updateSlot(slot, md)`（md 须单顶层块） |
| `insert_after_slot` | SSE `diff_slot_op` → `insertAfterSlot(slot, md)`（slot=0 文首） |
| `remove_slot` | SSE `diff_slot_op` → `removeSlot(slot)` |
| `batch_update_slots` | SSE `diff_slot_op` → span 替换合成 MD → `overwriteAll` |
| `overwrite_all` | SSE `diff_slot_op` → `overwriteAll(md)`（≠ `overwrite_document` 落盘） |

### `batch_update_slots`

```ts
{
  documentId?: string;
  ranges: Array<{ start: number; end: number; markdown: string }>; // 1-based 闭区间
}
```

| 规则 | 说明 |
|------|------|
| 单区间连续 | `start…end`，不许稀疏 |
| 多区间不相交 | 闭区间相交（含端点重合，如 `[3,8]`∩`[8,10]`）→ 工具报错 |
| 一次带齐 | 如改 `3–8` 与 `10–25` 必须同一次 `ranges`；拆两次会冲掉 pending |
| 门牌相对 base | 全部相对**本次调用前**文档；实现从高 `start` 往低 splice |
| 不必 1:1 | 每段 md 按 Markdown AST 拆外层块后**整体替换**该区间；块数可增可减；空 md = 删除该区间 |
| md 拆块 | **不是**按单换行；空行分段 / 标题 / 列表 / 代码围栏等各成一块（与 `markdownToLexicalJson` / lobe hydrate 一致） |

落地说明（一期）：Lobe 尚无原生 `batchUpdateSlots`；mdocs 在编辑器侧按门牌精确拼出提案全文后一次 `overwriteAll`。后续若 lobe 提供原子多段 Diff API，可改为直调并保持本工具协议不变。

## 写回

用户在 DiffHunk 上 Accept/Reject（或全部接受/拒绝）后，正文已是规范 Lexical；发布走既有草稿/发布链路。
