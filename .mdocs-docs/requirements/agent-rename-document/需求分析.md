# Agent 重命名文档文件名 — 需求分析

> 一句话：给智能助手加一个工具，在同一父目录下改文档的磁盘文件名（basename），不动父目录。

## 背景

已有 `move_document`：改父目录，**basename 不变**（见 `document-move`）。用户/助手要把 `foo.md` 改成 `bar.md` 时没有工具，只能删建或改库。

「文件名字」指路径上的文件名（`relative_path` 最后一段），不是顶栏展示名 `displayName`（展示名仍可走现有 `PUT` / 编辑器失焦保存）。

## 目标

1. Agent 工具 `rename_document`：按 `documentId` + 新 `fileName` 改 basename。
2. 同工作空间、同父目录；磁盘 rename + DB `relative_path` 一致。
3. 权限与可改类型与 `move_document` 对齐：仅创建者；`movable` 类型（md / html / sheet），不改文件夹。
4. 系统提示写明：改文件名用本工具，换文件夹用 `move_document`。

## 非目标（本期不做）

- 侧栏 / 右键「重命名」UI
- 改文件夹名、跨工作空间、移动+改名一步完成
- 单独为展示名再做一个 Agent 工具（需要时可后续加 `displayName` 可选参数，本期默认不碰）
- 批量重命名

## 验收标准

- [ ] 助手调用后，树与磁盘路径上的文件名更新；`documentId` 不变。
- [ ] 目标同父下已有同名文件 → 失败（与 move 的 409 同类）。
- [ ] 非创建者 / 文件夹 / 不可移动类型 → 明确失败。
- [ ] 后缀与类型一致（md→`.md`，html→`.html`，sheet→`.sheet`），沿用创建时的规范化规则。
- [ ] 本地草稿仍按同一 `documentId` 工作。

## 依据

- map：`map/backend.md`（document / file-store / agent tools）
- 需求：`document-move`（移动不做 basename；本期补文件名）
- 代码：`moveDocument`、`normalizeFileName`、`renameDocumentFile`、`moveDocumentTool`
