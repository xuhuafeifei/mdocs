# Agent xlsx 附件 — 设计契约

> 状态：**已同意（随实现）**

## 方案

在 `assetCapabilities` 注册 `.xlsx`/`.xls`，`parse/xlsx.ts` 用 SheetJS（`xlsx`）读 workbook，输出：

```json
{ "sheets": [ { "name": "Sheet1", "rows": [ { "列A": "v1" } ] } ] }
```

- `sheet_to_json(sheet, { defval: null })`：首行表头 → 对象行；空表 `rows: []`
- `JSON.stringify(..., null, 2)`；字符数 > `maxEmbedTextChars` → `deferred`
- MIME：`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` / `application/vnd.ms-excel`
- 前端 `accept` 追加 `.xlsx,.xls`；文件角标 `XLS`

不新开 LLM part 类型；与 CSV 同走 text 注入。
