# Agent xlsx 附件 — 需求分析

> 一句话：聊天可上传 `.xlsx`/`.xls`，服务端解析成 JSON 文本当附件内嵌给 LLM；过大则 `read_attachment`。

## 背景

Agent 附件能力表白名单原先不含 Excel；产品里的 `sheet_*` 只操作 mdocs `.sheet` 文档。用户需要把外部 Excel 丢进聊天让模型读表。

## 目标

1. 上传门禁放行 `.xlsx`、`.xls`（单文件 ≤ 5MiB）。
2. 解析为多 sheet JSON，走现有 `ParseResult.kind = "text"` 注入。
3. 序列化超 `maxEmbedTextChars`（12_000）时 deferred，可用 `read_attachment` 分段读。

## 非目标（本期不做）

- 导入为 mdocs `.sheet` / 改 `sheet_*` 工具
- 样式、合并单元格往返、公式源码
- `.xlsm` 宏语义

## 验收标准

- [ ] 可选/拖入 xlsx，上传成功
- [ ] 小表：user content 含 `【附件 …】` + JSON
- [ ] 大表：提示 `read_attachment`，工具返回 JSON 切片
- [ ] 未注册类型仍拒传
