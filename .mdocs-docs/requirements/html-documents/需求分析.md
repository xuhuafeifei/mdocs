# HTML 文档支持 — 需求分析

> 一句话：支持创建/展示 `.html` 文档（iframe 沙箱），与 md 平级复用权限与版本；草稿壳共用但内容按类型存；不进 FTS / 图谱抽取。

## 背景

mdocs 目前以 Markdown（磁盘 Lexical）为主。复杂布局、静态看板、Demo 页等场景需要 HTML 作为补充文档类型，且须与目录树、权限、commit 体系共存。

## 目标

1. 支持 `file_type=html`、路径 `.html`，与 Markdown 平级
2. 查看：iframe + 最严格 sandbox（禁 JS）
3. 编辑：源码 + 实时预览（textarea）；草稿/发布壳与 md 共用，payload 分 `lexical` / `html`
4. 冲突可走现有行级 merge；html 直通原文，不走 Lexical↔MD 桥
5. 用 shared **file_type 政策表**收口 tree/move/fts/graph/path/text 等热点

## 非目标（本期不做）

- WYSIWYG HTML 编辑、Monaco
- 执行 JavaScript（`allow-scripts`）
- HTML 评论、本地文件上传
- HTML 进入 FTS / 知识图谱抽取
- CLI 暴露图谱隐藏文件
- 每种 file_type 一个全能 Strategy 类（用政策表 + 按操作派发）

## 验收标准

1. 新建下拉可选 HTML；树中可区分
2. 预览沙箱禁 JS；编辑左右栏同步
3. 草稿/发布/move/权限与 md 同壳；内容形态按类型
4. 冲突 merge 对 html 可用（raw-text 管道）
5. 不进 FTS；图谱 walk 不抽取 html
6. `format=text` 对 html 不走 Lexical 提取
