# Agent run 拆分 — 设计契约

> **状态**：Phase 1–3 **已同意**（Phase 3：2026-08-05「可行，拆分」）

## 分层

```
tools-*.ts / template / registry   单个 tool → 主题集合 → createToolsForMode
run.ts                             mdocs 编排：校验 → tools → session → new Agent → 调 pi-run
                                   → 再发 context_usage + done
pi-run（`run-pi-agent.ts`）              只跑 Pi：subscribe(bindAgentEvents) → prompt → abort 收尾
tool-ui-effects.ts                 tool_execution_end → SSE（pi-run 内调用）
```

## Phase 3：`runPiAgent`

```ts
await runPiAgent({
  agent,
  message,
  signal?,
  visitorId,       // abort / finally → cancelVisitorChoices
  onEvent,
  sessionId,
  sessionManager,
});
// 返回 track（lastUsageInput / emittedError）供 run 合并 context_usage
```

- `bindAgentEvents`、`extractUser/Assistant`、session 落盘进 `pi-run`
- `createDeepSeekModel` / `toPiMessages` 留 `run`（装配侧）
- `context_usage` + `done` 留 `run`（产品收尾，不是 Pi）
