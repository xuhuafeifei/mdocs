# Agent 思考强度可配置 — 设计契约

> **状态**：已同意（2026-10-13 会话）。

## 方案摘要

| 项 | 约定 |
|----|------|
| 存储 | `agent_model_configs.thinking_level` TEXT，默认 `'low'` |
| 取值 | `off` \| `low` \| `high` \| `max`（非法 → `low`） |
| 运行 | `run.ts`：`thinkingLevel` 取自默认配置；`off` → Agent `thinkingLevel: "off"` |
| UI | 模型配置表单 MiniSelect「思考」 |
| Tool | `set_thinking_level({ level })` → 更新**默认**配置；禁止动 apiKey |

DeepSeek：`medium` 不暴露（会映成 high）。

## 变更触达

| 路径 | 说明 |
|------|------|
| `schema` + repo + `Config/config.ts` | 列 / 读写 / 归一 |
| `agent.routes` + 前端 `AgentConfigPanel` | API + 表单 |
| `run.ts` | 读档位 |
| `tools-*` + system-prompt | `set_thinking_level` |

## 风险

| 风险 | 处理 |
|------|------|
| 助手擅自调高 | prompt：仅用户明确要求时调用 |
| 旧行无列 | migration DEFAULT `'low'` |
