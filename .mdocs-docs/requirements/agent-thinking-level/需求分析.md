# Agent 思考强度可配置 — 需求分析

> 一句话：在模型配置里可选关 / 低 / 高 / 最大思考；助手可用 tool 只改当前默认配置的档位。

## 背景

DeepSeek V4 默认高强度思考；mdocs 曾写死 `thinkingLevel: "medium"`，官方会映成 `high`，体感「老在 thinking」。

## 目标

1. 模型配置卡增加「思考」档位：`off | low | high | max`（不暴露假 `medium`）。
2. 默认 `low`。
3. Ask / 帮写读取**当前默认配置**的档位。
4. Tool `set_thinking_level`：只改默认配置的档位；用户要求时才用。

## 非目标

- 改 API Key / 换模型 / 整套配置 CRUD
- 每轮临时档位（聊完还原）

## 验收

- [ ] 配置 UI 可选四档并持久化
- [ ] `off` 时无明显 thinking 流（或很快结束）
- [ ] Tool 改档后下一轮生效，返回当前档位
