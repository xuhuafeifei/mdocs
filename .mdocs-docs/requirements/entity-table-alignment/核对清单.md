# Entity ↔ 表 对齐核对清单

- **状态**：进行中（先做 A 列）
- **依据**：[ADR 023](../../decisions/023-entity-row-request-response.md) — 表 1:1 Entity（蛇形）；JOIN/子集用 `*Row`；HTTP 用 Request/Response
- **Schema**：`src/server/infra/db/schema.ts`
- **用法**：改完一项把「核验」勾上；问题记在备注

## 完成标准（每项）

1. Entity 接口名 = 表名风格（如 `Documents`），字段蛇形，列与 schema（含 ALTER）一致  
2. 自增 PK：`id: number | null`；insert 传 `null`，返回生成 PK  
3. insert 吃完整 Entity（缺列传 `null`），不用散参 / `Pick` / `Omit`  
4. repo SELECT 回 Entity 或 `*Row`；禁止 SQL `AS camelCase` 当「实体」  
5. 驼峰出参只在 `response/` + mapper
