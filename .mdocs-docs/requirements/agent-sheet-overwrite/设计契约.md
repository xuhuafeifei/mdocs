# Agent 覆写表格 — 设计契约

> **状态**：已同意（2026-10-10）。

## 方案摘要

| 项 | 约定 |
|----|------|
| 工具名 | `sheet_overwrite` |
| 语义 | **整表替换**指定工作表：新 `columns` + 新 `rows`；旧列/行 id 全部重建 |
| 范围 | 默认 active 表；可传 `sheet`（表名或 id）。其它标签不动 |
| 入参 | `documentId`；可选 `sheet`；可选 `name`（同时改表名）；`columns: string[]`；`rows: string[][]` |
| 行格式 | 二维数组，第 i 列对应 `columns[i]`（Excel 粘贴友好）。元素统一转成字符串，`null`/`undefined` → `""` |
| 上限 | `columns` 1～50；`rows` 0～500（允许空表「只留表头」） |
| 校验 | 列名 trim 后非空、同表内不重复；任一行 `length > columns.length` → 整批失败；`length < columns.length` → 右侧补空 |
| 权限 / 发布 | 同现有 sheet 写：`edit` + head 乐观锁，一次 `updateDocument` |
| 确认卡 | **不做**（与 `sheet_upsert_row` 一致；破坏性由工具名与 description 写清） |

共享层：`overwriteSheetTab(tab, { name?, columns, rows })` → 新 columns/rows，保留 `tab.id`，`name` 可选覆盖。

与 `sheet_insert_rows`（草案）分工：追加用 insert；整表换血用 overwrite。

## 工具契约（给模型）

- **label**：覆写表格
- **description**：用完整的列名列表 + 二维行数据，替换 `.sheet` 中某一个工作表的全部内容（旧行列作废）。不改其它工作表。局部改格/行请用 `sheet_set_cells` / `sheet_upsert_row` / `sheet_insert_rows`。md/html 正文请用 `overwrite_document`。写后直接发布。
- **parameters**：
  - `documentId: string`
  - `sheet?: string`
  - `name?: string`（新表名，可选）
  - `columns: string[]`（至少 1 个）
  - `rows: string[][]`（可为 `[]`）
- **返回**：`status`、`documentId`、`sheet` `{id,name}`、`columnCount`、`rowCount`、`headCommitId`

## 风险与回滚

| 风险 | 处理 |
|------|------|
| 误清整表 | description 写清「替换全部」；不做确认卡（若产品要卡，另开增量） |
| 助手仍调 `overwrite_document` | 保持拒绝 sheet；prompt 指向本工具 |
| 超大表 | 硬上限 500 行 / 50 列 |

## 测试要点

- 已有数据的表覆写为 2 列 3 行 → 只有这 3 行，列名正确。
- 同簿第二张表内容不变。
- `columns: ["A","A"]` → 失败。
- 某行 4 个值、只有 3 列 → 失败。
- `rows: []` + 合法 columns → 成功，空数据表。
