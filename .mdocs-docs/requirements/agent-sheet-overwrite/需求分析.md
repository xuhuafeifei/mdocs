# Agent 覆写表格 — 需求分析

> 一句话：给智能助手一个工具，整表替换 `.sheet` 里某一个工作表的列与全部行（一次发布）。

## 背景

`overwrite_document` **明确拒绝** `fileType=sheet`，表格只能靠 `sheet_set_cells` / `sheet_upsert_row` 等局部改。用户要「整张表换成这批数据」时，助手只能删行再建，又慢又易半截。

「Excel 表格」仍指 mdocs 的 `.sheet` 工作簿，不是上传 `.xlsx`。

## 目标

1. Agent 工具 `sheet_overwrite`：用新的列定义 + 全部行，**替换**指定工作表（默认 active）的内容。
2. 保留该工作表的 `id` / 表名（可选改名）；其它工作表不动。
3. 一次调用一次发布；列名、行数据用表格友好的二维结构（列名数组 + 行值数组）。
4. 系统提示：整表替换用本工具；局部改格/行仍用现有 `sheet_*`；md/html 仍用 `overwrite_document`。

## 非目标（本期不做）

- 用本工具覆写整份工作簿的所有标签（可后续加）
- 用户确认卡（与其它 `sheet_*` 写操作一致：有 edit 权即写；不做「直接覆写 / 帮写」分流）
- 导入真 `.xlsx` / `.csv` 文件
- 改 `overwrite_document` 去接收 sheet（保持分工清晰）

## 验收标准

- [ ] 调用后目标表只有传入的列与行；旧 `rowId` / `columnId` 全部作废（新 id）。
- [ ] 同工作簿其它标签内容不变。
- [ ] `columns` 为空或重复列名 → 失败，表不变。
- [ ] 行宽短于列数 → 右侧补 `""`；长于列数 → 失败或截断——**定稿：多出的单元格报错整批失败**。
- [ ] 非 sheet / 无 edit / 未知 sheet → 与现有 sheet 写工具同样失败。

## 依据

- `tools-overwrite.ts`：sheet 被 `overwrite_document` 拒绝
- `tools-sheet.ts` / `sheetDocument.ts`：局部写与工作簿模型
- 相关草案：`agent-sheet-insert-rows`（末尾追加，不整表替换）
