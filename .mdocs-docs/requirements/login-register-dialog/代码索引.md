# 登录 / 注册弹框 — 代码索引

> 本需求定位点（不含代码正文）。

| 路径 | 符号 | 说明 |
|------|------|------|
| `src/web/app/VisitorRegisterDialog.tsx` | `VisitorRegisterDialog` | 弹框主体；**已无 Tab 栏** |
| `src/web/app/VisitorRegisterDialog.tsx` | `page: "login" \| "register" \| "register-password"` | 三态状态机；默认 `"login"`（登录优先） |
| `src/web/app/VisitorRegisterDialog.tsx` | `switchToLogin` / `switchToRegister` | 两个底部入口；切换时清 `localError` |
| `src/web/app/VisitorRegisterDialog.tsx` | `loginMode: "password" \| "recovery"` | 登录子方式，保留自旧实现 |
| `src/web/app/VisitorRegisterDialog.tsx` | `goToPassword` / `submitRegister` | 注册两步；`submitRegister` 尾部含**不可达**的"切回登录"段（见遗留） |
| `src/web/app/VisitorRegisterDialog.tsx` | `handlePasswordLogin` / `handleRecover` | 两条登录路径；成功后 `storeVisitorId` + `props.onRecover` |
| `src/web/app/App.tsx` | `phase === "needsRegister"` | 唯一渲染该弹框的分支 |
| `src/web/app/App.tsx` | `handleRegister` | 注册回调；**末尾 `setPhase("ready")` 导致弹框卸载** |
| `src/web/services/endpoints.ts` | `registerVisitorApi` / `loginWithPasswordApi` / `recoverVisitorApi` | 三个接口，本次未改 |
