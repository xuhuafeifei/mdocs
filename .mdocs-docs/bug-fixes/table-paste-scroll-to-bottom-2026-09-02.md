# 表格内粘贴导致页面滚动到底部

> 一句话：表格单元格内 Ctrl+V 粘贴时页面视角迅速下沉、滚轮直接滚到页面底部。
> **状态：待办（未修复）**——仅记录现象，根因与方案待排查。

## 现象

- 在编辑器表格单元格内执行粘贴（Ctrl+V / Cmd+V）
- 页面视角迅速下沉，滚动条直接跳到页面底部
- 粘贴内容本身可能已正常插入，但视口位置被打乱

## 根因

待排查。候选方向（推测，未证实）：

- 表格块粘贴时插入大量行/节点，编辑器自动滚动定位逻辑（scrollIntoView / focus）作用到了错误的目标元素
- Vditor 表格编辑模式下，粘贴触发重渲染，DOM 高度瞬间变化导致容器 scrollTop 被推到底
- 粘贴事件冒泡到外层滚动容器，触发默认滚动行为

## 方案

待定。修复时优先排查：

- `src/web/app/DocumentEditor.tsx` 中粘贴相关处理（paste 事件监听、表格块处理）
- 编辑器包（`@lobehub/editor` 本地包 `../my-lobe-editor`）内 Vditor 的滚动定位逻辑
- 复现路径：新建文档 → 插入表格 → 在单元格内粘贴多行文本
